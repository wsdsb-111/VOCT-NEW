# V8.15.2 王国平级调任与候任等级复查

日期：2026-10-10。Three-Mod Character Name Compatibility 1.0.5；前版证据见[1.0.4 层级报告](v8.15.2-celestial-hierarchy-followup-report.md)。

## 确认的问题

1.0.4 的升迁入口要求旧主头衔严格低于新主头衔，因此国王到国王不进入升迁释放。地域复查则承认实际持有的合法副王国：如果旧任命王国尚未交出，其旧辖区公爵仍被判为合法。独立 QA 已执行旧版真实四文件 AST，复现旧王国、旧公国和旧直属公爵均未移交的状态。这个反例证明兼容层的兜底缺口，不证明用户存档一定经过了该路径。

不能把全部平级调任判为问题：汉番官职替换、天家宗仪遣派流官先执行 `force_step_down_landed_titles`，东方王朝替换先执行 `oe_governor_resignation_title_transfer_effect`，之后才授新官职。正常路径已有辞旧职步骤；原生天朝政府的 `admin_allows_holding_multiple_primary_tier_titles = no` 另有引擎约束，其文档明确适用于 appointment、appointment_succession、stepped_down，未列 granted。没有用静态分析断言这些机制在当前存档中的最终结算结果。

## 修复合同

保留国王到国王的平级调任。只在 `on_title_gain` 提供真实新任命王国、已知授官类型，并且角色仍持有另一任命王国时，记录实际获授头衔并安排次日交接。主头衔显示仍是旧王国也能进入检查；单纯切换显示主头衔、继承世袭王国或静态持有两个王国，不据此推断谁是新官职。

执行时再次核对角色、当前中国天朝霸权、本人天朝政府、任命法以及新头衔仍由本人持有。军镇等允许兼任的其他政府不做平级王国释放。旧任命王国按自己的合法 `current_heir` 交接，没有合格候任者则交回皇帝；平级交接允许同帝国内同级候任者，普通低阶官职释放的继任等级限制保留。随后复查外区低阶任命官职和公爵归属。世袭、宗藩、世族、租赁及无地头衔继续保护。

同一待处理窗口获得多个不同王国时，不以回调先后猜新职位，交接任务拒绝执行。兼容层交接产生的回调不递归安排平级交接。若原生或其他 Mod 已交出旧官职，则不重复移交；目标转出或资格改变时也不执行。

额外补上原生 `on_government_change`、`on_liege_government_change` 局部复查入口。回调仅按中国治下人物资格排队，次日执行仍要求完整政府及任命法，覆盖同日先转换政府、再补官职法的顺序。没有新增每日全体扫描或改动法理地图；未找到任意头衔法变更的原生回调，不能声称支持任意多日延迟加法。

## 候任等级审查范围

兼容层两个天朝 governor 类型已有 `allowed_candidate_tier = lower_or_equal` 和 `cooldown = yes`：高阶候选不符合低阶官职的等级政策，同阶符合。原有减一万分是额外评分措施，不能当作候选资格禁令。新增测试分别验证等级政策与评分，明确区分二者。

原版手动任命 `is_appointment_valid_trigger` 对天朝人物拒绝已有更高阶实地头衔，允许同阶。汉番封臣候选主循环使用 `<=`，三公的“调平同阶”明确支持同级王国调任；这些等号保持。

另有两项审查边界，未扩大修改：东方王朝 `chinese_bureaucracy` 使用本机 SDK 未文档化的旧 `allow_same_tier_candidates` 键，且未配置 cooldown；它绑定的通用流官法也用于军镇及中国以外，故没有通过全局覆写声称中国限定修复，自动平级资格仍需实机核对。汉番两条 courtier/guest 候选来源缺少封臣主循环的等级上限，但未证明高阶有地人物实际可进入这些容器，保留为待实机确认项。
