## 实施结果

- Subjective World 将 Policy Facts 与 Prompt Facts 分开选择：前者负责知情判断，后者只选择可安全渲染的当前事实；兼容字段 `allowedFacts` 保留，诊断元数据不再占用 Prompt 的 24 条槽位。缺失 Realm 节点继续 fail-closed。
- 第三人召回新增 Entity-grounded `ThirdPartyEvidencePatch`：按实体、查询相关性、主体中心度、重要性、置信度和时效排序；每个实体最多 2 条、320 Token，总计不超过 512 Token。证据保留来源与 epistemic status，冲突时明确拒绝猜边。
- `ThirdPartyEvidencePatch` 只在本轮明确识别到场外实体且当前 NPC 的人物目录存在可访问记录时触发，位于 Current User 之后并标记为动态块。生产 Subjective World 开启时，旧 Mentioned Character Info 不再绕过统一 Knowledge Policy。
- 新增结构化 DeathFact 与确定性时间格式器，保留 deceased、killer、deathDate、cause，按程序计算今日/昨日/前日/周/月/年表达；已故年龄固定为 birthDate 到 deathDate，不随当前日期增长。
- 新增 Kinship Graph 与统一亲属称谓，覆盖父母、子女、共享父母证明的兄弟姐妹、祖父母、叔伯姑舅姨、侄甥、堂表亲、当前/前任/已故配偶。任意多种关系类型冲突均返回未知并记录诊断。
- Prompt 增加当前结构化家庭事实，并冻结“当前 CK3 状态优先、Memory 只补充过去经历”的权威规则；Chat Cache Anchor 从 v4 升至 v5。
- 用量元数据新增 Mentioned Snapshot、Turn Recall、Third-party Evidence、Total Memory 和 Worldline Token 字段，不保存正文、ACL 或秘密内容。
- 按用户要求将可见 UI 标签更新为 `Memory Engine 2.6 · V8.6.2`；内部存储 schema、摘要文件格式和 `MEMORY_ENGINE_VERSION=2.5` 保持不变，不触发迁移。
