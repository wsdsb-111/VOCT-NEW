# V8.4.1 Hotfix Luna 实施报告

## 当前结论

Luna-H1 与 Luna-H2 的前端实现已完成，Luna-H3 的真实 CK3 展示 Gate 待人工复验。Prompt Default On 保持关闭。

## 已完成

- 新增专用 `promptTokenBreakdownRows()`，按 `label`、block `id` 和 `tokens` 展示 World Prompt 分块；不再使用只认识 `title/body/visibility` 的 Supplemental Renderer。

- 诊断页增加 Resolver 诊断区域，预留并展示 Localization Reverse Lookup、Historical Alias Resolver、Runtime Identity Resolution、sourceComplete、scannedFiles、missingDescriptors、matchedRawKeys、definitionId、runtimeId 和 matchSource。
- Resolver 字段缺失时显示未提供，不把诊断状态伪装成 Game Truth；实际 Resolver 数据由后续 Terra-Hotfix 透传。
