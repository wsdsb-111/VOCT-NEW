普通凡人、原版 hunter、witch、勇敢／贪婪／私生子等不因此获得感知能力，也不会单独产生猎人感知。按本地 PoD 1.20.1 的规范 trait ID 判断，不按中文名字猜测。

重叠角色只选一类。恶煞优先于残留吸血鬼／狼人身份；附身者、造物等实际改变身份的标记优先于原始身份；萨卢布里治疗者／战士／守望者等职分不覆盖种族。不能利用被隐藏的具体身份所残留的基础特质绕过遮盖。

## 精确识别与细分信息

- 纯血龙族／龙王与其他超自然者双向精确认种族；普通人无此能力。
- vampire／werewolf／supehunter 三方继续精确互认。
- 同一规范种族身份可精确认出；血族、地狱、生灵按此前确认各自组内精确互认，跨组仍只感知大类。
- 传说组按同源身份互认：fae／changeling／kinain；kueijin／dhampyr；mummy／asekh_sen。妖精不能凭此精确认出木乃伊，狼人不能凭此精确认出芭丝特。
- 精确识别只授予基础种族，不授予氏族、妖精血脉、木乃伊分支、兽族次分支或职分。即使纯龙也不获得这些细分特质。
- 仅自动种族识别（感知或政治身份认知）的主 trait 使用固定基础名称和空描述；不输出原动态名称、别名或描述。例如 spirit 的“狼人先祖”、fae 的“首生妖精”等动态细分名称不会随基础身份泄漏。认知面板临时事实带 `speciesOnly`，原始来源哈希保持，可继续手动隐藏。明确披露、手动已知或既有完整资料来源仍可提供完整 trait。政治认知原有身份 ID 授权不缩减，单一类别优先规则仅限定本次感知。

本轮保护清单覆盖原生 39 个非凡人主身份、103 个次身份与 21 个相关身份，共 163 项；mortal 和 chargen 开关排除。次身份本身不充当额外感知能力或主种族识别捷径。原生变量决定的动态名称共享主 trait；本轮不导出新的变量或计算 Akuma 等未独立导出的谓词身份。

## 生效范围

只在当前玩家开启的当面对话中按需判断：玩家与所有实际在场 NPC，以及这些 NPC 之间的每一对，均可双向感知。候场、暂离、离场、死亡、仅提及、未选中人物、信件和缺少显式在场名单的调用不触发。

`Conversation.end()` 只标记停用，不进行结束时感知；即使旧调用保留在场名单，也不能再触发。下一次开场重新启用当前资料的判断。没有计时器、后台任务、世界扫描或全人物认知链。感知不写持久披露记录；真实台词披露仍只保存给当时实际在场者。当前玩家由本次 GameData.playerID 决定，继承／主动换角不迁移旧玩家知识。

感知沿现有认知面板、资料投影、听众对回应者的定向知情和动态 responder-game-facts 进入提示词；大类事实仅含七个固定标签与通用措辞，不携带真实种族 ID／别名／描述，不授予姓名、头衔、性格、秘密或旧对话。
