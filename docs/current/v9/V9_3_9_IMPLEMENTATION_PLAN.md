## 保留合同

完整 Recent2、合法官方追忆与当前玩家—回应 NPC Pair 事项簿保留；不得把玩家与全部 NPC 的事项簿累加到一个请求。窗口容量从实际配置读取；用户将自行由 128,000 设置为 192,000，不硬编码。

摘要已冻结仍占每次请求的上下文 Token。应用保证原文复用和稳定前缀条件；Provider 是否实际命中由原生 cached-token 数据证明。只显示玩家的一行本场上下文，不逐 NPC 显示或累加请求。

Legacy Summary、协议 3.0、存储 2.5／schema 2、Official Action 2.0.3 保持。Character Knowledge 不依赖退役 Memory4、Durable 或惰性 Sidecar；不恢复旧检索、提取、Year/Life 或重建。原 V9.3.7 和 V9.3.8 验收记录保持原版本归属。

## 外部交接

年龄“实际值 +1”的真实首次偏差必须由同日期 CK3 面板、原始导出、Parser、canonical、resolver、家庭块、Prompt 和模型回答对照后判定。新增诊断代码的通过不能写成真实根因已经定位。

Workshop 新导出格式通过仓库补丁交付，由用户应用后重新加载 Mod 并导出新日志。静态 reverse／apply check 只证明补丁与安装文件对应，不证明游戏已加载。
