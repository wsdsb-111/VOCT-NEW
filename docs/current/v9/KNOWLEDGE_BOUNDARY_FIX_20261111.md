# 2026-11-11 人物认知本地修复

基于本机V9.7.1，保留版本号；修复源码并通过确定性构建本地安装。未提交或推送远端，未执行完整远端发布门禁。两个兼容Mod仍独立构建和安装，本次Runtime修复不调用其源码。

## 已复现与修改

1. **好感明细绕过特质过滤**：原有投影会过滤target.traits，但默认pList把responder.opinionBreakdowns中指向目标的reason原样发送。新增按目标人物收集未获知姓名、头衔、特质别名，清理对应派生文本；保留数字、无关原因及回应者本人的同名特质。嵌套同ID副本不会绕过处理。
2. **其它身份旁路**：陌生人的信仰、文化和修正可能透露氏族或物种，即使文本不含种族特质名称；它们不再作为陌生人的自动可知资料下发。未知头衔的统治者／骑士标记置为未知，已知English pList模板在运行时跳过未知身份推断，不修改用户模板文件；titles/titleCandidates数组按同一披露授权过滤。原有有来源的五代亲属／合法配偶互知范围保持。
3. **亲口披露漏识别**：允许锚定的“我告诉你，……”及“告诉你吧，……”直述前缀；否认、疑问、条件、转述、内心独白、明确说明是假的或故事仍拒绝记录。
4. **已知事实缺少明确提示**：过去只单列已知姓名；现在把有效的已知特质和头衔逐项加入当前回应者的动态消息。共同保持owner→target、战役、日期、来源修订和手动隐藏检查，不授权未列出的秘密或其它事实。原记录写入链未发现普遍丢失，不宣称已修复不存在证据的存储故障。
5. **用户确认的新特质披露规则**：肯定说明中出现真实特质名称及明确人物指向，就披露给当时实际在场的全体人物。支持我／你／他／她、点名、明确受话者与同主语并列特质；多人指向不唯一时不猜测。否认、提问、假设、转述他人话语、内心独白、明确虚构不算。特质陈述本身作为独立来源，不要求说话者此前已有该项认知；仍核对当前真实特质和原始发言修订。每位在场者分别保存听众证据，候场／暂离者不补发。此项只调整TRAIT；姓名、头衔、称号仍沿用原披露规则。

手动认知方向应为“谁知道＝NPC，知道谁＝玩家”。标记后从下一次新请求验证；不会改写已经生成的回复。手动隐藏影响当前结构化认知，不重写原始发言、已授权历史记忆或真实游戏事实。

3. 新场次亲口说出角色确实具有的身份，例如“我告诉你，我是吸血鬼。”；核对实际听众的认知面板与下一次回复，候场人物不应同时获得记录。
4. 两人对话说“你是吸血鬼”，或多人对话点名后说“他是吸血鬼”，核对目标身份及每位实际在场者的单向认知；多人只说“你／他”且无法唯一指向时，不应记到任意人物。特质低声发言同样按用户要求对全体实际在场者生效，其它事实继续遵守原听众范围。

若旧对话或已授权摘要中已经明说某项信息，不能用该场次检验“初次见面完全未知”；使用新NPC和新对话区分历史信息与当前资料泄漏。
