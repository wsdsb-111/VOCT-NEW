## 实际路径

`test-v9.3.6-token-comparison.js` 输出政策矩阵、非记忆 Prompt 余量、输出预留、格式化成本及三种布局的结构化结果；`test-v9.3.6-conversation-budget.js` 调用真实 Conversation 与 PromptBuilder，断言 Worldline 完成后才执行无记忆 dry-run，再确定记忆预算。输出、协议与安全余量继续使用既有 `planRequestBudget`。标题、日期、交互证据、正文和逐条消息开销都计入；最终 Provider 对实际消息跨度与指纹复算，超额在发送前阻断。

同源且同修订、已完整出现在实际 Recent 文本中的事项保留 item 与计数，展示为“详见近期摘要”；Recent 截断处未完整出现的事项保留完整正文。不使用语义相似度删除事项。固定快照保持序列化字节一致，只在合法来源、Campaign、日期、玩家身份、配置或可用余量变化时失效。
