# 2026-11-13 超自然会面感知与种族互认

最新七类感知、同源互认、次身份遮盖和对话结束停用以[后续补充](PERCEPTION_GROUPS_20261113.md)为准。本页保留原一般基线与历史验证证据。

后续纯血龙族／龙王双向识别及特殊关系全资料例外，以[同日补充报告](DRAGON_SPECIAL_KNOWLEDGE_20261113.md)为准。下表保留本轮一般感知基线。

本轮在按需社会认知上增加当面感知。按用户最后两次修订，**吸血鬼、狼人、PoD猎人组内精确互认，猎人与组外也有普通超自然感知**。此前将吸血鬼／狼人互感设为模糊、将猎人组外设为无感知的中间规则已取消。

## 最终规则

| 观察者与目标 | 由本机制获得的信息 |
| --- | --- |
| vampire、werewolf、supehunter组内任意组合 | 精确认出目标在该组中的身份 |
| 共享同一规范超自然身份特质 | 精确认出共同身份；不自动公开目标的其他身份／血统 |
| 其余超自然组合，包括猎人与组外 | 只察觉非凡气息，知道属于超自然存在，具体种族未辨明 |
| 普通人、仅有原版hunter／witch／勇敢等普通特质者 | 不新增感知能力 |
| 候场、暂离、离场、死亡、仅提及、信件、缺显式在场名单 | 不产生当面感知 |

神通术师`theurgist`、术士`sorcerer`、超能力者`psychic`均按用户确认加入普通超自然身份集合。原版`witch`和`hunter`不因此加入；不能以中文相似名或hunter子串识别。

感知不授予姓名、头衔、家族、具体血统、其他特质或私密数值。既有政治／亲属／明确披露等合法来源可提供更强知识；手动隐藏继续优先。本机制不降低已有认知，也不把“感到异常”当成“已公开真身”。

## 数据与提示词边界

- `social-recognition-policy.js`的纯本地判定只读取当前对话角色的规范trait ID，校验当前玩家／campaign、日期、显式实际在场名单、生命状态及非信件场景。不会扫描世界人物或访问兼容Mod源码。
- 精确识别仅向现有`traitKeys`通路授予匹配的身份。模糊识别使用独立`PERCEPTION/supernatural_presence`临时事实，固定值为“察觉到非凡的气息，属于超自然存在；具体种族未辨明。”；别名为空，没有真实种族ID、特质对象或描述。
- 资料投影仅增加同样的安全`supernaturalPerception`文字，真实未知特质保持删除。认知面板将其显示为“感知”，并区分会面认种族与只感到气息的来源。
- `character-disclosure-context.js`在原动态`responder-game-facts`中注入合法感知，同时按听众→回应者逐人判断自我伪装。只感到非凡气息的听众仍不知具体真身，不得用专属气息、外貌或能力线索暗示真实种族。普通人听众不会因另一名超自然听众感知到而自动获知。
- 当面感知不写`disclosures-v1.json`，不创建后台认知目录。下一次当面对话重新判断；如果角色在台词中肯定说出真实特质，则原有规则仍向当时实际在场者保存明确披露。
- 继续使用当前`GameData.playerID`，继承／主动换角不迁移旧玩家个人知情。Prompt缺少在场名单时，原通用人物回退也不能激活新感知。

Runtime仍为9.7.1，原Prompt块ID、缓存锚点、IPC方法、协议3.0与存储2.5保持；新增感知是只读临时事实，不改变持久披露记录格式。本轮没有修改CK3导出脚本，也没有构建、调度或更新两个独立兼容Mod。现有通用trait导出已提供所需ID，无需另加饥饿度／经验值字段。

## 用户手动验证

自行重启VOTC并重新发起当面对话。使用无亲属／政治／旧披露关系的测试人物，以免更强的已有知情掩盖感知规则。

1. 吸血鬼↔狼人、吸血鬼↔猎人、狼人↔猎人：双方均能认出对方身份；不因此知道姓名／头衔。
2. 吸血鬼↔木乃伊、猎人↔龙／术士／超能力者：仅觉得气息非凡，不能直接叫出具体种族。
3. 狼人↔狼人、同一类术士／超能力者：可认出共同身份，不连带得知其他血统或秘密。
4. 同场加入普通人：普通人不会获得未听到的气息识别；候场／暂离者不应感知场内人物，信件不应触发当面感知。
5. 手动隐藏身份后不得被新自动识别绕过；切换到另一个玩家角色后仍只使用新角色自己的认知。
