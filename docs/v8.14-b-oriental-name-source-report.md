# V8.14-B INC06：东方帝国称谓来源调查

## 结论

已定位会放大 INC06 影响的 VOCT 称谓别名缺陷；原始显示名污染尚缺对应运行日志。称谓别名推导曾把 `shortName` / `fullName` 当作头衔证据。东方帝国的显示名可带有退位称号；因此渲染姓名中的“皇帝”等字样会被误判为角色身份，再生成“陛下／皇帝／天子／官家”等泛称。文件记忆路径的 `assignLatestHonorific()` 有独立推导逻辑，也读姓名字段；而资料本身已设 `allowDerivedHonorifics: false`，这段逻辑仍可能绕过该限制。

修复只让派生称谓依据结构化 `primaryTitle` 与 `titleRankConcept`：

- `resources/app/out/main/memory-system/character-identity.js:80-96`：用于实时人物提及的推导证据仅为主头衔和头衔等级。
- `resources/app/out/main/memory-system/memory-engine.js:403-417`：文件记忆中的最新称谓推导同样仅检查这两个结构化字段。

`firstName`、`shortName`、`fullName`、`nickname` 和明确提供的 `mentionAliases` 仍按原逻辑保留为字面提及别名；没有删除、清洗或截断任何称号字符串。两条路径当前既有别名集合也未被强行统一：实时人物别名包括“官家”，文件记忆推导集合不包括“官家”。
