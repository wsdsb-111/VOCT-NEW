# V8.12.1：双时间记忆实施记录

状态（2026-09-24）：**V8.12.1.1 审查修复与本地自动发布 Gate 通过；V8.12.1 CK3 / Provider 实机 Gate 和远端 CI 待验收。** 用户确认的 `V8.12 PART 3 = PASS` 单独记录于 [Part 3 施工与验收记录](v8.12-part3-memory-engine-3.0-implementation-report.md)，不等同于本版实机验收。

## 已实施合同

- `temporal-anchor-extractor.js` 只从终局原始消息及当场 CK3 游戏日期解析明确年份、年月日、相对年/月/日等时间表达；保留来源 `messageIds`、精度、绝对日期窗口和 `event/past_conversation/unknown` 角色。含糊、假设、无有效日期或无来源 ID 时不制造 Event Time。模型自行返回的时间字段不作为证据。
- `memory-engine.js` 在 Final Summary 质量校验后按来源消息 ID 把时间引用绑定到 Segment 和持久 Memory；本地时间解析失败只令引用为空，不能令有效正文摘要提交失败。恢复快照保留对话日期与 `campaignToken`。`perspective-projector.js` 仅从各 Owner 可见的 Segment/Memory 投影引用，并校验引用与投影一致；`game-data.js` 在 schemaVersion 2 摘要顶层写入 `temporalRefs` 与战役标识，原 `summary.date` 继续表示对话发生日期。
- `memory-store.js` 把摘要顶层引用读取为 `memory.provenance.temporalRefs`。不同时间证据的同文投影不合并；旧摘要没有新字段仍可读取，原无引用摘要的会话键保持原样。编辑摘要正文保留原来源引用，删除与缓存失效后对应索引消失；不扫描旧正文补造年份。
- `summary-date-index.js` 建立 Conversation Time 与 Event Time 双索引。Event Time 仅接收当前 Campaign、当前 Owner、有 Segment 或持久 Memory 绑定且 `timeRole=event` 的引用；Conversation Time 保留旧摘要日期兼容，但旧摘要无 Campaign 标记不能进入有标记战役。`fuzzy-temporal-resolver.js` 以当前 CK3 日期解析查询窗口，区分事件、对话及混合意图，保存最近成功回复的同场时间焦点。场景、战役、对话或话题切换会终止继承；单纯游戏日期推进不会清除绝对时间焦点。
- 时间候选经过当前 Owner 与关系路由、主题/实体排序，再进入共享动态 **Extra≤3**。精确时间查询无目标窗口命中时不拿其他年份 Topic/Important 填充；已成功注入的摘要留在该 NPC 的私有 Prompt 历史，后续追问不重复插入，历史压缩移除后可再次召回。Recent2、官方追忆与内部稳定块的冻结位置、预算、Prompt block ID 和 GLM Stable Prefix 均未改变。
- `memory-trace.js` 记录时间轴、目标年份、双索引候选数、实际命中数、焦点复用、缺失及预算略过情况、Stable/Dynamic Token；Provider 返回缓存 Token 时另记 `provider_cache_usage.cachedTokens`。真实缓存命中率仍以 Provider usage 为准。
- Part 3 收尾：官方追忆在 Prompt 预算不足时按带日期的**完整事件**裁剪，事件正文中的空行不会截断事件；摘要编辑器提示新对话可能从 CK3 原生记录覆盖当前同步副本。摘要 63/64/65 块与失败后恢复边界补入专项回归。

## V8.12.1.1 审查修复（2026-09-24）

- Campaign 读取由空标记通配改为严格相等：当前战役有标记时，旧版无标记摘要仍可查看/编辑/删除，但不进入最近摘要、Stable/Direct、Topic/Important、时间或旧版 Turn Recall/第三人证据；当前战役和存储均无标记时仍可召回。
- 手工编辑摘要会将原始来源消息与时间窗口重新绑定至新 Segment ID，并同步到摘要顶层、结构化 Memory 和 Episode；进程重启后 Event Time 索引继续有有效来源。
- 终局原始消息的时间证据也绑定到结构化持久 Memory ID。Owner 投影同时收集其可见 Segment 和持久 Memory 的引用；Event Time 接受任一有效绑定，仍拒绝无来源或非事件引用，其他 Owner 不获得私有事实。
- 时间焦点按 Campaign、对话 ID 和真实场景修订号隔离；仅游戏日期推进不会清除同一绝对时间窗口，明确新时间、话题切换、超过三轮或场景变化仍清除。中文“说了、讲了、问了、告知、登基”等问法进入相应时间轴；未改变模型调用次数。
- Windows 主题测试读取文本时统一 LF，附 CRLF 断言；未修改交付 CSS 或 Git 换行配置。新增 `test-v8.12.1.1-review-fixes.js` 并登记发布清单，覆盖 Campaign 隔离、私有引用、无绑定拒绝和 22 条时间问句。
