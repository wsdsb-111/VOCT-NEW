# V8.4.1 Luna-6 Prompt Diagnostics 实施报告

## 结论

Luna-6 已完成。世界线诊断页新增只读 Query / World Recall 检查，可在 Prompt Integration 仍关闭时人工验收世界线 Prompt 组成，不会修改存档、Supplemental 或 Default On 设置。

## 实施范围

- Main 新增 `getPromptDiagnostics({ query, assistContext })`，复用 Terra 的 Shared Query Analyzer、Checkpoint Freshness 和 Prompt 选择结果。
- 诊断结果包含 Query、解析实体、命中的 Game Truth、命中的 Supplemental、Checkpoint `asOf`、Live Date、Freshness、World Prompt Token、Token 分块、Cache Hit 和被裁剪条目。
- Supplemental 的 Top 3 限制、Game Truth 人物/头衔查询上限会以裁剪项返回，不把未注入 Prompt 的候选伪装成已命中。
- 诊断入口通过 `worldline:getPromptDiagnostics` 接入 IPC 和 preload；Renderer 只使用 `window.worldlineAPI`，不直接访问 Node 或文件系统。
- 诊断调用允许检查关闭状态下的候选 Prompt，但生产 `getPromptContext()` 仍受 `promptIntegrationEnabled` 门禁控制。
