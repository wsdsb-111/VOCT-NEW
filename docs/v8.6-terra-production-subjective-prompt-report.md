## 已实现

- `world-knowledge-classifier.js` 将检索候选拆为字段级事实并附 Checkpoint / candidate / field evidence：角色姓名为 `PUBLIC_WORLD`，地点为 `COURT_PUBLIC`，头衔持有人为 `REALM_PUBLIC`，明确年度战争为 `PUBLIC_WORLD`，其余事件和无日期/无证据字段保持不输出而非整体升级为公开。
- `subjectiveWorldMode` 新增显式 `PRODUCTION`，但默认仍为 `DIAGNOSTIC`，`promptIntegrationEnabled` 默认仍为 `false`；不会因升级自动改变用户现有对话。

- `PromptBuilder` 只注入一个 `worldline-subjective` 提示词块。生产构建失败时会继续对话，但不调用旧的未过滤 `getPromptContext()` 回退。
- Phase B 将 legacy `historicalReferenceInfo` 替换为同形、时间安全对象；标准模板不再接收未过滤的当前帝王/年号字段。没有新 block 的旧自定义模板仍可读取原四字段形状，不会抛错。
- 私人记忆仍由既有 Memory Engine 定向召回；生产世界线块只序列化已授权、带正文的 Game Truth / GameState / Annual Delta / Public Supplemental，绝不序列化 secret body 或 opaque memory reference。
