世界线仍是 CK3 事实只读层。现有世界线启动过程会重新构建 checkpoint；本轮只读复核没有写用户 checkpoint。新增字段诊断不升级 `schemaVersion: 1`，身份绑定继续一对一、未知/冲突 fail-closed。

## 公开身份与人物认知

姓名保留为 NPC/角色的主体识别标识，按用户要求不新增 NAME 披露类型、不物理隐藏姓名。身份使用现有 TITLE 的主要头衔、等级、宫廷/内阁职位及已有候选，特质使用 TRAIT，年龄沿用 AGE 的披露时数值与获知日期。

修复实际对话投影中未保留 `sourceRole` 的接线缺口。Scanner 明确区分玩家发言、NPC 可绑定的直接对白和严格第一人称肯定自报；NPC 无引号的自报不再一概遗漏，Assistant 的普通第三人旁白不再被当作公开发言。缺失或不支持的 role 不猜测为 user。

独立对抗测试另复现“我是皇帝的朋友”“我有勇敢的弟弟”等修饰性用语误授权；事实词后的 `的/之 + 名词` 与英文所有格修饰不证明发言者本人拥有该头衔/特质。尾部约束保持句末“勇敢的。”等合法肯定自报，不扩大为猜测性自然语言推断。

| 来源 | 处理 |
| --- | --- |
| 自己明确公开当前头衔/特质 | 在实际听见的其他 Owner 下，记录目标人物和原话证据；不为自己重复添加知情记录。 |
| 别人直接公开某人的当前头衔/特质 | 唯一姓名/昵称及合法对白 provenance 绑定目标，实际在场 Owner 保存，目标不必是发言者。 |
| NPC 肯定的第一人称自报 | 严格识别当前身份/头衔/特质及既有年龄句式；不得把内心描写或第三人旁白升级为对白。 |
| 旁白、否认、疑问、传闻、假设、未来、歧义人物 | 不产生自动披露。 |
| 迟到、离场、私密片段 | 继续使用 Presence/knownBy/visibility，不扩散给没听到的人。 |
| 已验证信件 | 保留接受/投递来源 Gate 和收件人 Owner，不重发、不凭扫描绕过 Gate。 |

持久化顺序为：叙事已提交 -> 遗忘过滤与来源验证 -> Known Evidence -> 确定性披露 -> 长期抽取。故长期 Provider 失败或 `NO_DURABLE_CONTENT` 不应再阻止合法披露。重试保持幂等，已删除来源不能复活；Fact Epoch、手工隐藏优先级、冻结 Profile 与下一场生效合同不变。

这些修复解释了可复现的接线和终局缺口，但未读取用户真实对话原文，不冒认用户每次未显示的唯一原因。查看方向仍是“谁知道谁”：玩家公开给 NPC 的事实在 NPC Owner 目录下，不在玩家目录下为自己添加。

## 数据与兼容边界

- 用户已新开存档并清空旧摘要，本版不增加旧摘要迁移、回填或额外兼容功能。仅保留共享接口和既有授权/存储合同，防止影响新档终局、信件及失败重试；实机验收以新档为准。
- 同一份实际 autosave 只读复核：日期 `1046.1.1`，112,156 人物；44,210 名存活角色的信仰全部解析成功，已有文化映射 32,326 个。纯数字 faith/culture 输出均为 0，未解析 rite/faith/culture 引用均为 0；读取前后源大小和 mtime 不变。未启动 CK3 或写 checkpoint，不等于实时游戏验收。
- 旧 100 条 Detail 的事件时间 unknown 不自动改为交谈日。Year/Life 仍仅按合法 observed/reported 事件年份生成；计划、未知和仅获知日期不补年，不凭空修写旧正文。
- 不自动改写现有披露、摘要、恢复队列或存档。新代码可恢复仍有合法材料的旧任务，但已丢失来源不凭空回填。
- 完全关闭游戏后缺少可信会话/GameData/Campaign 的独立档案浏览入口没有新增；页面不可读不等于持久文件被删。
- 审查中父母/直属领主字段覆盖偏低的权威字段链、外部手改文件缓存及大 checkpoint/Delta 的性能风险仍是待核查项，不用推测性字段映射或重构冒充修复；本次收口七项已确认问题。
- 前端功能标签为 V8.15.1；Memory Engine 显示 4.0、协议 `engineVersion: 3.0`、摘要存储 2.5、App 包 2.0.4 不变。目录、IPC、Owner/Campaign、1200 token cap、Prompt Block IDs、Cache Anchor、Official Action 基线和 App/Mod 独立发布关系不变。
- 本轮没有修改 Workshop、Three-Mod、真实摘要、settings、pending letters、debug.log、autosave 或 API 凭据，没有调用真实 Provider。

## 用户实机 Gate

1. 同场自报及他人直接公开当前头衔/特质，结束对话后查看听者 NPC 的人物认知；下一场复核实际 Prompt 行为，离场者不应获得记录。
2. 长期抽取失败后重试、关闭重开后重试：已提交叙事和 Detail 不重复，合法日期的 Year/Life 补生成，手工版本不被覆盖。
3. 新版存档世界线的信仰/文化与实际 CK3 对照；字段已解析不代表所有 UI 本地化或实时关系均完成实机核验。
4. 信件接受后双向摘要/长期记忆/披露、删除后重试及多战役切换；保留用户此前信件通过记录，但本轮新链路仍需复测。
5. 真实 Provider 输入、缓存遥测、长时 Soak。以上自动化结果不签发 Full Freeze。
