# V8.7.2 Luna 实施报告

## 1. 范围

本阶段承接 V8.7.2 Terra 的 Current Truth、CK3 Load Session 和 Legacy Supplemental 合同，只修改世界记忆编辑器的玩家可见交互，不改变服务端事实核验、分支判定或旧记录持久化格式。

## 2. 已完成

- Current Claim 改为“选择涉及人物 → 选择六项支持字段 → 读取 CK3 当前事实 → 查看只读预览”。页面不再提供当前状态值的手填输入；保存只提交服务端返回的 `rawValue`，服务端仍会再次核验。
- 生产可选字段收敛为 `location`、`alive`、`faith`、`culture`、`liege`、`courtEmployer`。玩家界面不再展示没有生产解析来源的 `primaryTitle` 和 `imprisoned`。
- 新增可读的 Current Truth 预览、失败原因和编辑旧记录时的重新读取提示；角色或字段改变后旧预览立即失效，避免把旧选择提交到新字段。
- `LOAD_BOUNDARY_CANDIDATE` 进入前端不可写门禁。页面明确提供“继续当前分支”和“建立独立分支（不继承旧 Canon）”，不会自动把新的 CK3 载入会话接到旧分支。
- Legacy Supplemental 以“只读”列表呈现。公开记录可打开迁移草稿；非公开记录先显示“迁移审阅”，只有明确点击确认后才调用迁移 API。页面不提供旧记录编辑、删除或直接写回入口。
- 旧版 Supplemental 为零时显示明确空状态；迁移完成的旧记录显示 Canon 目标并保留只读历史状态。
- 页面版本标签更新为 `V8.7.2`，并通过既有 preload/IPC 的窄接口接通 `getCanonCurrentTruth`、`listSupplemental`、Legacy migration 和 branch confirm/fork。
