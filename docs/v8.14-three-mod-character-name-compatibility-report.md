# V8.14 三大 Mod 人物称谓兼容补丁

## 目标

在东方王朝、汉番礼制、天家宗仪同时启用时，消除三者对 `CHARACTER_VIEW_NAME` 等全局本地化键的互相覆盖；保留天家宗仪称谓分派，并让未被天家宗仪或汉番专属规则处理的人物继续使用东方王朝的庙号/谥号和通用 UI 姓名规则。补丁依赖三款 Mod，不直接修改其 Workshop 文件。

## 实现

- 新增独立本地补丁 `compatibility-mods/VOTC_Three_Mod_Character_Name_Compatibility/`，启动器描述符依赖以下三个现有名称，确保补丁排序在它们之后：
  - `Oriental Empires (All Under Heaven)`
  - `Eastern Ritual and Governance 1.99 (oe ver.0.5)`
  - `天家宗仪 V0.76`
- `CHARACTER_VIEW_NAME`、短名、提示名和头衔历史统一保留天家宗仪现有 `SanGong_*` 分派；该分派本身先检查天家宗仪规则，并已有汉番专属称谓路径。
- 对 `SanGong_view_name_fallback` 与 `hanfan_view_name_fallback`，补丁接入东方王朝的 `HasMiaohaoShihao` → `Loc_china_MiaohaoShihao` 选择，其余情况回到 `OE_GetUINameNotMeNoTooltip`。因此只接管两套分派的普通回退，不复制或重写三方完整条件树。
- 人物提示名称、年龄提示和 Outliner 名称引用统一后的 `$CHARACTER_VIEW_NAME$`，避免仍走另一套硬编码显示路径。
- 未修改 VOCT 的 `log_character` 输出或解析代码。现有 `t_1` / `t_2` / `t_3` / `t_18` / `t_26` getter 保持原值：带头衔姓名、完整含绰号姓名、主头衔名、名字、主头衔等级概念。

- 静态核验：三个依赖名与当前 Workshop 描述符完全一致；9 个本地化覆盖键存在；YML 为 UTF-8 BOM；启动器路径使用本地 `mod/` 相对路径；安装目录与仓库源一致。
