# V8.4.1 Luna UI 实施报告

## 结论

V8.4.1 Luna-1、Luna-2、Luna-3 已完成静态实现与回归检查。世界线前端现在从 Terra 的 `politicalContext` 读取已证明的政治语义，并将本地化结果按“可读名 + 原始键 + 置信度 + 来源”展示；后端无法证明的字段保持“未知 / 未确认”，不由前端猜测补位。

## 实施范围

### Luna-1：UI 可读性与长字段

- 枚举状态和来源标签保持 `white-space: nowrap`，避免 `PLAIN_TEXT_SAVE`、`PUBLIC_WORLD`、`NORMAL` 等值被拆开。
- 语义卡片、历史人物绑定行和长 ID 单元格允许在容器边界内安全换行。
- 历史人物 `figureKey`、`definitionId` 和语义对象的 `rawKey` 支持鼠标 tooltip；同时提供复制按钮，复制失败时不改变事实状态。
- 语义字段使用独立 Grid，保留原有三套主题和约 1024px Overlay 的响应式结构。

### Luna-2：Localization UI 接入

- 世界概览默认展示 Terra Resolver 返回的 `displayName` / `localizedValue`。
- 诊断辅助信息同时展示 `rawKey`、`confidence` 和 `sourceFile` / `sourceMod`；多来源冲突显示来源数量，不隐藏冲突。
- `NOT_FOUND`、`CONFLICT`、动态值和未知政治事实不会被前端转换成猜测名称；没有证据时统一显示“未知 / 未确认”。
- 前端没有新增 `ipcRenderer`、文件系统访问或按 key 自行猜译的字典。

### Luna-3：世界概览语义化

概览新增并按证据链展示：

- 玩家主要头衔
- 直属领主
- 顶层 Realm
- 顶层 Realm 统治者
- Checkpoint 日期、Live 日期与 Checkpoint 新鲜度

原有活跃战争、历史绑定、Delta 待处理和 Supplemental 数量仍保留。直属领主独立时显示“独立”；其余无法证明的对象不使用枚举顺序或旧的 `currentRuler` 字符串补位。
