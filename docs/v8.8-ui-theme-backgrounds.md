## 可读性处理

- 主对话/配置面板及其内容区使用对应背景图叠加主题专用遮罩，背景图覆盖整块外挂 UI，而不是只作为按钮图片。
- 根据实机截图，外层与内容层遮罩已降为半透明；`messages-container`、`config-main-content`、世界线卡片、诊断卡片和世界记忆编辑器不再使用近乎纯白的高不透明背景，因此三张原图的边饰、纹理和构图能够保留。
- 针对世界线页面再增加主题专用的对比层：游牧使用冷灰蓝面板与卡片，水墨使用暖褐面板与卡片；辅助说明、诊断和解释文字统一切换为深色高对比色。
- 输入框、下拉框、状态标签、世界线状态色和世界记忆提示色按浅色/深色主题分别设置，避免继承旧主题的低对比度白色或灰色。
- 2026-09-11 根据水墨主题实机反馈，将对话外层与内容层由偏白遮罩调整为低强度青灰遮罩，适度降低背景亮度而不压暗正文和输入控件；功能图标改为黛青灰，悬停使用暖铜，当前主题使用朱砂。错误、警告和成功等语义状态图标保留原色，避免颜色含义丢失。
- 2026-09-11 根据摘要页与游戏对话实机反馈，水墨摘要卡姓名由亮银墨影改为无阴影深黛墨色，摘要数量与人物 ID 改为沉铜色；游戏对话区与配置页分离为稍深青灰底，玩家、NPC 与系统对话框分别增加暖褐或青灰半透明底色，降低白纸眩光并保留背景纹理。
- 2026-09-11 完成三主题整体视觉审计：游牧按钮改为织纹皮革、铜边与八角皮牌轮廓；骑士按钮使用黑钢切面、双侧铆钉和硬边文字阴影；水墨按钮使用宣纸渐变、黛青墨线与朱砂主按钮。游牧浅色摘要改用深黛色姓名，骑士摘要移除模糊光晕并保留单像素金属阴影，水墨沿用深墨姓名和沉铜元数据。
- 2026-09-12 根据实机截图移除游牧马首图标自带的深色方形底图，并将骑士主题切换器与图标按钮的黑色填充改为透明；纹章、边框、选中标记及三个内部主题键保持不变。
- 内部主题键不变；没有改动 CK3 存档、Worldline/Canon、Prompt 或 Memory 数据合同。
