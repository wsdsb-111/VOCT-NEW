# V8.8 UI 主题背景补充

## 状态

代码施工完成，静态回归与发布回归通过；打包 Electron 的三主题人工视觉验收仍需用户在本机确认。

## 主题映射

保留原有 `parchment`、`knight`、`ink` 内部键，避免破坏已有 `localStorage` 主题设置；实际视觉资源改为：

| 内部键 | 玩家名称 | 背景资源 |
| --- | --- | --- |
| `parchment` | 游牧 | `image/草原游牧.png` |
| `knight` | 骑士 | `image/中世纪骑士.png` |
| `ink` | 水墨 | `image/中国古典.png` |

主题切换按钮的标题和 ARIA 标签已同步到上述名称；按钮继续使用原有主题控制图标，只负责切换风格。

## 可读性处理

- 主对话/配置面板及其内容区使用对应背景图叠加主题专用遮罩，背景图覆盖整块外挂 UI，而不是只作为按钮图片。
- 根据实机截图，外层与内容层遮罩已降为半透明；`messages-container`、`config-main-content`、世界线卡片、诊断卡片和世界记忆编辑器不再使用近乎纯白的高不透明背景，因此三张原图的边饰、纹理和构图能够保留。
- 针对世界线页面再增加主题专用的对比层：游牧使用冷灰蓝面板与卡片，水墨使用暖褐面板与卡片；辅助说明、诊断和解释文字统一切换为深色高对比色。
- 输入框、下拉框、状态标签、世界线状态色和世界记忆提示色按浅色/深色主题分别设置，避免继承旧主题的低对比度白色或灰色。
- 内部主题键不变；没有改动 CK3 存档、Worldline/Canon、Prompt 或 Memory 数据合同。

## 验证

- `node scripts\\test-v8.8-ui-style-backgrounds.js`：通过，验证三张图存在、整块面板 CSS 映射、原有主题控制图标未变和遮罩/控件可读性规则。
- `node --check resources\\app\\out\\renderer\\assets\\index-Dn3qWlAB.js`：通过。
- `node --check resources\\app\\out\\renderer\\world-memory-editor.js`：通过。
- `node scripts\\test-release.js`：通过，264 个发布组、333 个测试文件分类、68 个历史检查归档。
- 现有 Electron 启动烟雾测试在当前机器的 Chromium GPU 进程异常退出并超时，未把该环境问题计为 Renderer 主题失败；实际视觉仍需在用户本机重启 VOTC 后切换三种风格确认。
