# V8.14.1 前端显示内容同步

日期：2026-10-04。范围为当前中文/英文主要界面文案及记忆总览说明；独立 QA 使用 GPT-6 Luna Max。

## 内容更新

- 底部区分功能版本 `V8.14.1` 与 App 包版本。保留 `getAppVersion()` 和包 `2.0.4`，没有把功能版本写入 Electron 更新版本。原绝对定位存在遮挡正文的风险，最小 CSS 修复使其在 Flex 正常流中占位；桌面与窄窗均检查版本标签和正文不重叠。
- 摘要页标识 Memory Engine 4.0，展示人物认知、官方追忆、人生、年度、详细长期记忆和 Legacy；摘要记录计数不再称为全部“可编辑”，也不冒充长期条目数。
- 终局视角摘要说明区分 Narrative 正文提交与 Durable 长期提取；无可确认长期内容、缺 CK3 官方导出时保持真实空状态。归档仅供只读查看。
- 优化页更新为当前功能内容：Recent2 冻结、Memory4 动态概览/细节限制、人物知情和特质边界、Detail 与 Year/Life 来源、ACK 与效果回读区分。旧动作 A/B/C 实验明确为历史/已退役，不恢复旧动作模式。
- 世界书、官方追忆、历史检索、主观认知诊断移除旧 V8.7/V8.12/Phase A 阶段标题；世界记忆标签改为“当前分支”，保留 CK3 当前事实只读和 Campaign/分支隔离。
- Provider 界面移除旧 RC3/V8.9/V8.10 阶段标题，保留现有兼容开关；缓存效果以服务商返回用量为准，不保证命中率。既有 GLM Cache v2 不冒充 V8.14.2 调优。
- 完整信件流程显示尚未完成实机验收；GLM 缓存调优仍延期至 V8.14.2。已有陌生人首次对话和用户测试特质的 PASS 不扩大为所有 Gate。
