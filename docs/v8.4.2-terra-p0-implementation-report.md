# V8.4.2 Terra P0 实施报告

## 已完成

- Historical Alias Catalog 只提供候选 Definition ID；`historical-identity-resolver` 以 V8.3 的同一评分权重、85% 阈值、15% 差距和硬冲突规则完成 Runtime 身份判定。
- Shared Query Analyzer 拆分 `resolvedCharacters` / `candidateCharacters` 与 title 对应集合；兼容字段 `characters`、`titles` 仅保留已解析的 Game Truth。歧义候选保留 Runtime、Definition、raw name、score、evidence 与 conflicts，不输出权威 display name，也不进入 Prompt topic facts。
- War parser 仅接受 `character` / `participant` 显式字段中的已知 Runtime ID；分数、贡献和其他数字只写入拒绝诊断。未知显式 Runtime ID 也会被记录而不进入 actor。
- 仅从 active war 列表消失的战争改为 `WAR_NO_LONGER_ACTIVE`、`DERIVED_GAMESTATE`、`UNKNOWN`、`RECONCILIATION_PENDING`；不会再伪造 `WAR_ENDED`。Delta actor 仅包含下一快照中存在的角色。
- 玩家补充知识统一为 `PLAYER_SUPPLEMENTAL`，与派生 GameState 结果分开。CJK 泛问词不会触发 Supplemental 召回，必须存在实体锚点或显式实体标签。
- Checkpoint 新鲜度新增 `verificationMode`：`LIVE_VERIFIED`、`CHECKPOINT_ONLY`、`STALE`，并透传给 Overview、Diagnostics 与 Prompt Diagnostics。
