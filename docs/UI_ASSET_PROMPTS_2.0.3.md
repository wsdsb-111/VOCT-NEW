# VOTC 2.0.3 UI asset prompts

本组素材使用 Codex 内置图像生成工具生成，目标是为外挂 UI 提供可切换的历史风格按钮。所有图标均要求透明背景、无文字、无徽标、无水印，并在 32–48 像素下保持清晰轮廓。

## 羊皮卷

```text
Use case: stylized-concept
Asset type: square game UI icon for a CK3 companion application theme selector
Primary request: an aged medieval European parchment scroll, partially unfurled, with a small dark-red wax seal and restrained illuminated-manuscript corner ornament
Style/medium: polished hand-painted historical strategy game UI icon, realistic material texture, crisp silhouette
Composition/framing: single centered object, slight three-quarter view, generous transparent padding, readable at 32–48 pixels
Lighting/mood: warm candlelight from upper left, dignified court atmosphere
Color palette: old ivory parchment, antique gold, oxblood red, charcoal shadows
Materials/textures: fibrous vellum, worn rolled edges, embossed wax
Constraints: genuinely transparent background; no text; no letters; no logos; no watermark; no border frame; no extra objects; square composition
```
