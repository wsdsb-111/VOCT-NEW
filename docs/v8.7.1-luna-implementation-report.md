# V8.7.1 Luna 玩家优先世界记忆 UI 实施报告

## 范围

本阶段完成 V8.7.1 Luna 的世界记忆编辑、召回引导和诊断可读性层。Terra 已提供的 Branch、Current Truth、人物选择和 Canon 测试能力保持不变；本阶段不修改 CK3 存档解析、Memory Engine 数据格式或默认生产召回开关。

## 已实现

- `world-memory-editor.js` 改为玩家优先的基础模式：标题、自然语言正文、成立时间、记忆类型、可见性、重要性和涉及人物均可直接填写；不再要求玩家先输入 Runtime ID。
- 增加五类模板：普通剧情事实、秘密约定、CK3 未记录事件、长期世界规则和未来计划。模板只预填表单，不绕过服务端的时间、权限、分支和 Current Truth 门禁。
- 人物选择器复用 Terra 的 `listCanonCharacterOptions`，提供当前场景/最近提及的可读候选；指定人物可见性和作用域默认从已选人物推导，Runtime ID 仅保留在高级选项中。
- 高级选项折叠展示类型、Runtime ID、known-by、scope、冲突标识、会话固定、revision/branch 和来源调试信息，保留开发诊断能力但不阻挡普通创建流程。
- 记录卡片增加“测试这条记忆”入口。通过 `testCanonRecall` 选择 NPC 和问题，展示是否召回、原因、权限、时间、分支、CK3 当前事实冲突、Token 和最终 Prompt 预览，并将内部原因映射为可读文案。
- 召回未开启时显示可操作引导，明确要求 `Worldline Prompt Integration = ON` 与 `Subjective World Mode = PRODUCTION`；新增窄接口 `worldline:setRecallSettings` 只允许修改这两个设置并清理相关缓存，不修改模型、CK3 存档或保存内容。
- 修复历史版本列表“加载更早版本”覆盖旧结果的问题，改为按最新到最旧追加展示；分支异常、回档候选和冲突状态在技术信息折叠区保留明确提示。
- CSS 增加表单双列、人物候选、测试结果和窄屏单列布局；600px、1024px、1280px、1440px 宽度均不依赖横向滚动才能完成核心操作。

## 边界与交接

- Playwright fixture 不是打包 Electron 原生窗口，也不等价于真实 CK3/Provider 实机验收；本阶段不宣称 FULL FREEZE。
- 当前默认 `promptIntegrationEnabled` 仍关闭，UI 不会在保存记忆时隐式开启召回。下一步由 Sol 审查设置接口、召回权限/时间/分支边界、测试面板的敏感信息、生产 Prompt 连接和真实 Electron/CK3/Provider Gate。
