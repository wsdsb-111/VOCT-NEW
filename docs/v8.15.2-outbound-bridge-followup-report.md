## 可复现的执行缺口

旧 `votc_runtime_bridge.gui` 在 `talk_scene` 存在时停止执行正式 `votc.txt`，依赖 `talk_window_counter` 处理。两者生命周期不同：对话窗口／counter 已销毁而全局场景仍残留时，日期桥继续输出日期，但正式信件、动作及关闭对话命令都没有这个后台消费入口。手动重试不能作为自动恢复方案，因为未知 Effect 不得自行重放。

修复限定为全局桥只在玩家有效时执行正式载体，不再依赖对话场景和窗口。周期、只读 DATE、旧日期管道退役和对话窗口入口保持；游戏侧同 command ID 去重及应用 ACK FIFO 仍负责防止两个入口重复执行。此修复消除已构造的消费缺口，不改寄出日期算法、不自动重试 STALLED，也不宣称已恢复缺失的历史日志证据。
