# V8.15.1 三主题阅读与布局优化

日期：2026-10-06。按用户要求优化排版、字体与视觉舒适度；功能版本仍为 V8.15.1、App 包仍为 2.0.4。本轮保留此前世界线与记忆修复的未提交改动。

## 设计与实现

- 三主题键及图像不变：`parchment=游牧`、`knight=骑士`、`ink=水墨`。外层仍显示原主题背景与图标；阅读区加强覆盖层，减少背景细节与文字竞争。浅主题采用低亮度灰绿纸面，骑士采用柔和炭灰，保留主题材质而非整页纯白/纯黑。
- 界面优先使用 Windows 本地 Microsoft YaHei，提供中文 fallback；水墨只在标题保留楷体。界面文字 14px、辅助文字 12-13px、记忆长正文 16px；对话正文继续服从现有 `--message-font-size` 用户设置，不随窗口宽度缩字。
- 字距归零，移除阅读区的继承模糊阴影，增强浅主题说明文字与帮助图标对比。新纯色阅读区的正文、辅助、成功、警告与错误色均达到 4.5:1；图像/透明叠层仍需截图复核，该数值不代表每个旧页面都已达到 WCAG。
- 主导航自动换行，主题切换与关闭保持可见；Memory4 标签随可用宽度自动分列，世界书标签换行，不依赖细横向滚动条。世界书绑定/候选网格自动换列；人物认知与表单依据配置面板容器宽度收为单列，而非只看整个窗口宽度。
- 阅读正文、字段、日期和操作区增加间距，按钮减少纹理和阴影，选中状态统一为清晰填色；保留图标按钮、语义危险色、键盘焦点及减少动态效果的系统偏好。
- 修复语言菜单浅底浅字：语言名称、代码徽章、选中勾和悬停态使用各主题颜色。菜单宽度固定为 220px 并按可用窗口约束，左/右定位均有边界，保留九种语言与原切换行为。
- 真实窄窗鼠标命中发现顶部拖动层遮挡第一行按钮；导航控件置于拖动层之上，空白区域保持鼠标穿透。顶部缩放边缘与空白拖动区仍保留，不修改窗口拖动/缩放的处理逻辑。
- 提示词编辑页的页头、区块标题/工具、预设字段按可用宽度换行，避免长标题和按钮合计最小宽度挤出窄面板；预设字段不再压缩为不可读的窄条，编辑文本移除继承阴影。

新增 `resources/app/out/renderer/ui-comfort.css`，在既有主题 CSS 与 Memory4 CSS 之后加载；bundled JS 仅精准修改语言菜单定位表达式，不重生成其他资源，不修改 IPC、设置键、Prompt、Owner/Campaign、记忆/信件逻辑或用户数据。`ui-theme-preview.html` 使用同一层样式并支持窄窗口，仅为静态预览，不替代打包窗口验收。
