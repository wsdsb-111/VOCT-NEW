# V8.4.1 Terra Phase A 实施报告

本阶段只实现 V8.4.1 的两个 P0 Gate：Checkpoint Source Revision race 防护，以及基于 `de_facto_liege` 证据链的玩家政治上下文解析。未开始 Localization、中文 Query Analyzer、Freshness、Delta V1.1 或 UI 扩展。

## 已实现

- `WorldlineService` 在实际存档来源改变时递增 `sourceRevision`；每个构建记录自身的 revision 与 source path。
- Worker 返回、文件稳定性检查、失败处理与持久化前均确认 revision 和 source 仍为当前值。旧构建返回 `worldline_build_superseded`，不得激活、写入或覆盖当前来源的 Checkpoint。
- 当前 revision 的重复重建继续复用同一 Promise；来源变更后的新 revision 可立即开始新构建，不等待旧 Worker 完成。
- 新增 `resolvePlayerPoliticalContext(snapshot)`，从玩家 `domainTitles` 出发，沿 `de_facto_liege` 查找最高玩家持有头衔、直属领主、顶层 Realm 与其 holder。
- 存在多个独立玩家顶层头衔、缺失 parent、循环或玩家 domain 证据不足时返回 `UNKNOWN`/明确 reason，不从 titles 枚举顺序或 key 前缀猜测。
- `getOverview()` 与 `getWorldKnowledge()` 改用 Political Context Resolver；保留现有字段兼容，同时补充 `directLiege`、`topRealmTitle` 与结构化 `politicalContext`。

## 真实存档只读核验

- `primaryTitle = h_china (#14185)`；
- 无 `de_facto_liege`，因此 `directLiege = INDEPENDENT`；

该结论来自 domain 与层级字段，未依据 `h_` key 的字面含义或 title 列表位置推断。
