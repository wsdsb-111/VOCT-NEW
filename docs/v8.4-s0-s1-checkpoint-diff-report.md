## Terra：Title Holder / History Diff

- 识别 `1,186` 个同 ID title 的 holder 变化。
- S1 history 在 `1154.1.1 < date <= 1155.1.1` 中明确记录新 holder 的有 `286` 个，标记 `HOLDER_CHANGED_RECONSTRUCTABLE`。
- 另有 `900` 个只有 S1 current holder、没有可验证的窗口内 holder history，标记 `HOLDER_CHANGED_CURRENT_ONLY`。
- 因此 Title reconciliation 为 `PARTIAL`：有 history 证据的变更可由 GameState 重建；current-only 变更不得直接丢弃 supplemental delta。

三个规定样本的实际结果：

| 样本 | Title ID / Key | S0 holder → S1 holder | S1 history | 结论 |
| --- | --- | --- | --- | --- |
| 玩家主头衔 | 14183 / `e_ylsg` | 121091 → 121091 | 无窗口内变更 | 稳定 |
| 主要帝国 | 1391 / `e_byzantium` | 98428 → 98428 | 无窗口内变更 | 稳定 |
| 玩家发生 holder change 的头衔 | 15720 / `d_huixun` | 121091 → 96798 | `1154.12.29`，`appointment`，holder `96798` | `HOLDER_CHANGED_RECONSTRUCTABLE` |

`d_huixun` 证明 title record 的 current holder 与 history 可以共同重建该次变更；它不证明全部 1,186 条都具有同等历史保留。

## 解释边界

本报告确认了人物 Runtime ID 稳定对齐、死亡桶变化、新人物出生、历史人物跨 checkpoint 存在性，以及 Title/War 的实际重建边界。死亡转移与 title/war 数量仍是 checkpoint 结果，不等同于已捕获每一条游戏事件的精确发生时刻。特别是 56 个结束战争候选没有 S1 可重建记录，正式 V8.4 不能从 GameState 单独推导完整 `WAR_ENDED` 事件。
