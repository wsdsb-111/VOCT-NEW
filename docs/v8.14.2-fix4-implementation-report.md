## 问题与修复

旧归属逻辑先检查冒号或已知说话动词。像“乙冷笑，“……””“乙拍案——“……””这样的动作型引语可能因此落入无归属 fallback，并被误记为当前 fragment speaker 的话，造成第三人头衔/特质披露错误。

在 `resources/app/out/main/memory-system/memory4-entity-context.js` 中改为 identity-first：提取引号前最近 clause，按完整角色表匹配最长唯一姓名/昵称，再与当前 speaker ID 比较。其他人物、歧义身份、复合主语及归属到随从/下属的 possessive 表达 fail-closed；保留同一 speaker 与没有反向归属证据的纯直接引语。引号后的说话标签也参与归属与内心、转述、书写来源检查。没有扩展动作动词白名单。

未改 Fact Epoch、Owner、Presence、Worldline、Disclosure 持久化或 App/Mod 外部依赖合同。测试并入已经登记的 `scripts/test-v8.14.2-third-party-disclosure.js`，无需增加 manifest 项。
