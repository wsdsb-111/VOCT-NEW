# V8.4.1 Hotfix Terra 实施报告

## 目标与范围

本阶段修复真实 CK3 环境中中文 World Recall 的身份闭环，不开启 `Prompt Default On`，不修改存档、Supplemental、Prompt block 顺序或 Provider/Cache 合同。

## 已实现

- Localization Reverse Lookup 保留 typed 文件扫描，但当未命中时回退扫描同语言目录内其余 `.yml` 文件；人物名不再要求文件名包含 `name` 或 `character`。
- Reverse Lookup 改为诊断对象：`MATCHED`、`NO_MATCH`、`CONFLICT`、`INCOMPLETE_SOURCE_SCAN`。缺 descriptor、来源发现失败或扫描上限不再伪装成空数组。
- 新增冻结的 Historical Alias Catalog。仅收录已由 V8.4 历史勘探确认的 Definition ID：岳飞/岳武穆对应 `nansong_yue_085`、`tangyin_yue_014`；辛弃疾对应 `han_12371`、`licheng_xin_006`。
- Shared Query Analyzer 按 Runtime ID、Definition ID、Historical Alias、Localization Alias 的顺序建立候选；Historical Alias 只能经 `snapshot.definitionToRuntime` 产生 Runtime Character，绝不从名称猜测 ID。
- 新增 `resolverTrace`，提供 Localization 的状态、完整性、扫描数、缺失 descriptor、raw key，以及 Historical Alias 的 definition/runtime/provenance。
- 已确认 Historical Alias 命中 Runtime 时不再进行昂贵的反向 Localization 扫描，诊断明确记为 `NOT_REQUIRED_HISTORICAL_MATCH`；角色显示名优先采用确认的历史别名，避免存档中的单字 first-name 降级显示。

## 冲突与边界

- 同一中文 Localization 值对应多个 raw key 时返回 `CONFLICT`，不建立身份别名。
- 同一 Historical Alias 对应多个 Definition 时保持 `AMBIGUOUS`，将全部已被当前 Checkpoint 直接绑定的 Runtime ID 返回并保留来源；不静默选择其中之一。
- Reverse Lookup 使用查询值扫描与结果缓存，而非在主进程常驻全量语言值表。单次扫描上限为 5000 个文件；超限会返回 `INCOMPLETE_SOURCE_SCAN`。
- 本阶段未扩充未经勘探确认的人物 Catalog，未处理完整 Definition Catalog winner、Save A/B、Provider/KV Cache，且生产 Prompt 继续关闭。

## 验证

- 新增 `test-v8.4.1-hotfix-localization-layout.js`：非标准 `nansong_l_simp_chinese.yml` 可回退命中人物 key。
- 新增 `test-v8.4.1-hotfix-incomplete-source.js`：缺失 Mod descriptor 返回 `INCOMPLETE_SOURCE_SCAN`。
- 新增 `test-v8.4.1-hotfix-historical-alias.js`：岳飞 Alias 通过 Definition 直达 Runtime，并公开多 Definition 歧义。
- 新增 `test-v8.4.1-hotfix-query-e2e.js`：真实 Resolver + Analyzer + `WorldlineService.getPromptDiagnostics`，不 mock `findLocalizedKeys()`。
- 定向回归、语法和 test manifest 检查通过：162 个测试文件、93 个 release groups。
- 真实本机 Checkpoint 只读 Gate：`岳飞现在在哪里` 命中 `nansong_yue_085 → #96896` 与 `tangyin_yue_014 → #96895`；Trace 为 `historical=AMBIGUOUS`、`runtime=MATCHED`、`localization=NOT_REQUIRED_HISTORICAL_MATCH`。这是预期的冲突保留，不是单一人物选择。
