### 2. 对话摘要系统（Past Summaries）

#### buildPastSummariesContext() - 对话摘要加载

**修改前**：
```javascript
let context = `Here are the most recent conversation summaries between ${char.shortName}, ${gameData.playerName}, and other characters:

${summary.date} (${timeAgo}): ${summary.content}

${char.shortName} also remembers recent conversations with people mentioned in this dialogue:
```

**修改后**：
```javascript

${summary.date}（${timeAgo}）：${summary.content}

${char.shortName} 还记得与对话中提到的人物的近期交谈：

${summary.date}（${timeAgo}，与 ${conversationWith}）：${summary.content}
```

#### buildFinalSummary() - 摘要生成提示

**修改前**：
```javascript

buildConversationText(history, "Full conversation:")

buildConversationText(newMessages, "Recent conversation:")
```

```javascript

content: "此对话的先前摘要：\n" + currentSummary
```

### 3. 记忆系统（Memories）

#### 对话记忆模板

**修改前**：
```javascript
template: "Relevant memories:\\n{{#each memories}}- {{this.creationDate}}: {{this.desc}}\\n{{/each}}"
```

**修改后**：
```javascript
template: "相关记忆：\\n{{#each memories}}- {{this.creationDate}}：{{this.desc}}\\n{{/each}}"
```

#### 信件记忆模板

**修改前**：
```javascript
template: "All memories:\n{{#each memories}}- {{this.creationDate}}: {{this.desc}}\n{{/each}}"
```

**修改后**：
```javascript
template: "所有记忆：\n{{#each memories}}- {{this.creationDate}}：{{this.desc}}\n{{/each}}"
```

#### 默认模板（fallback）

**修改前**：
```javascript
const tpl = template || "Relevant memories:\n{{#each memories}}- {{this.creationDate}}: {{this.desc}}\n{{/each}}";
```

**修改后**：
```javascript
const tpl = template || "相关记忆：\n{{#each memories}}- {{this.creationDate}}：{{this.desc}}\n{{/each}}";
```

#### 信件完整记忆模板

**修改前**：
```javascript
const tpl = template || `All memories for the involved characters:
{{#each memories}}- {{this.character}} | {{this.creationDate}} ({{this.creationDateTotalDays}}): {{this.desc}} [relevance: {{this.relevanceWeight}}]
{{/each}}`;
```

**修改后**：
```javascript
const tpl = template || `所有相关角色的记忆：
{{#each memories}}- {{this.character}} | {{this.creationDate}}（{{this.creationDateTotalDays}}）：{{this.desc}} [相关性：{{this.relevanceWeight}}]
{{/each}}`;
```

## ⚠️ 注意事项

### 1. 已有摘要不会自动更新
- **旧摘要内容**：仍然是原样（中文或英文取决于当时使用的语言）
- **新摘要标题**：会使用新的中文格式
- **建议**：可选择清空旧摘要重新生成（Settings → Summaries → Clear All Summaries）

### 2. 用户自定义的模板
- **影响**：只修改了默认fallback模板
- **用户模板**：如果用户在UI中自定义了模板，不会被覆盖
- **建议**：建议用户手动更新自定义模板为中文

### 3. 预设（Presets）
- **影响**：已保存的预设不会自动更新
- **建议**：如需中文化，需要编辑预设或删除重新创建

### 4. 重启要求
- **必须重启**：修改了 `main.js`，必须重启应用才能生效
- **热重载**：只修改 `.hbs` 文件可以热重载
