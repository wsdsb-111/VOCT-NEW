## Sol 修复

- 修复 Canon Test 将记录自身实体当成查询实体的问题：只有测试问题实际命中存档人物名称时，才形成实体相关性；无关问题不再误报命中。
- 修复隐藏、恢复等局部更新重复执行完整时间归一化的问题：不涉及时间字段的更新不再改写 `TIMELESS`、`PLANNED`、日期或冲突键。
- 修复分支恢复候选 DTO 与 UI 合同不一致，并校正优先级：当前精确检查点保持当前分支；正常日期前进自动延续；命中归档指纹时恢复对应分支；多个归档候选保持 fail-closed 供玩家选择。
- Current Claim 强制使用 `CURRENT_DATE`，且人物必须存在于当前 Checkpoint；Court/Realm 范围人物同样由服务端校验。结构化声明不能由自由文本或客户端字段绕过。
- Canon Test 遵守生产召回总开关；关闭时返回 `RECALL_DISABLED` 且不返回 Prompt。Secret 未授权结果不返回正文、声明值或 CK3 当前值。
- 召回设置端点严格校验空输入、布尔类型和模式枚举；设置更新只清相关缓存，编辑器不会因设置事件被关闭或清空。
- 玩家 UI 增加结构化 Current Truth 编辑、CK3/记忆值对照及“改为过去事件 / 取消当前状态声明 / 隐藏此记录”处理；会话固定只对符合合同的记录开放。
