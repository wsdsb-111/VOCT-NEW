# V8.7.1 Terra 后端实施报告

## 范围

本阶段落实 V8.7.1 的 Terra Stage 1–3：分支连续性、Current Game Truth 结构化合同、时间合同、人物选择/Canon 测试 API 与单实例写入保护。未改 Luna 的世界记忆页面；UI 交互、模板和引导留给 Luna。

## 已实现

- `branch-registry.json` 兼容读取 schema v1，并在后续写入时保存为 schema v2。正常同路径且游戏日期向前的存档自动延续原 Branch；同日不同内容继续 fail-closed；日期回退返回 `ROLLBACK_CANDIDATE`；指纹命中同路径 archived Branch 时安全恢复原 Branch。复制到不同路径仍创建独立 Branch，不自动继承。
- Branch 记录保留当前指纹、有限指纹历史、最新游戏日期、状态、父 Branch、fork/archive/last-seen 时间。恢复的 Branch 重新进入可写状态；分支 API 新增显式 resume 入口，供后续 UI 处理歧义候选。
- Canon 新增 `temporalMode`（当前日期、指定日期、长期规则、未来计划）与 `temporalSemantics`。当前日期由服务端写入当前 CK3 日期/总天数；长期规则可无日期召回；未来计划以“尚未发生”语义召回；指定日期缺失会被拒绝。
- Current Game Truth 只允许 `CURRENT_STRUCTURED_CLAIM` 进入当前状态验证链，支持 location、alive、faith、culture、liege、primaryTitle、courtEmployer、imprisoned。自由文本中的“现在/现居/仍在/迁往/现任”等状态声明没有结构化 claim 时拒绝保存，不能作为当前事实注入 Prompt。
- Canon Service、Worldline IPC 与 preload 新增人物候选、Canon 召回测试和 Branch resume API。测试 API 复用生产 Retriever、权限、时间、分支和 Current Truth 门禁；未授权 Secret 返回拒绝状态且不返回正文或 Prompt 预览。
- 主程序启动前调用 Electron 单实例锁；第二实例立即退出，主实例收到 second-instance 事件时仅恢复并聚焦现有窗口，避免两个 VOTC 同时写同一 Canon store。
- Revision History 后端按最新修订在前分页；Luna 需将“加载更早版本”改为追加展示。

## 验证

- 新增并登记 18 个 V8.7.1 Terra 发布用例，覆盖正常 autosave 推进、Canon 跨检查点持续、回档、archived resume、恢复写入、复制隔离、结构化 Current Claim、自由文本门禁、日期/长期/计划时间合同、角色选择、测试 API、Secret 脱敏和单实例锁。
- `node scripts/test-v8.7-production-canon.js`、各 V8.7.1 定向测试、主进程/Worldline/IPC/preload 语法检查与 `git diff --check` 通过。
- `node scripts/test-release.js`：222 个发布组通过；manifest 覆盖 291 个测试文件，68 个历史检查归档。

## 交接与边界

- P2 per-branch Worker 并行未实施，当前仍保持 root 级串行，避免扩展并发写入面；按设计延期 V8.8。
- 单实例锁保护打包 Electron 的同一用户目录，不构成跨机器或手动绕过 Electron 的文件锁。
- Luna 仍需接入基础/高级模式、模板、人物选择器、召回开启引导、Current Truth 冲突交互、Branch 恢复提示和 Canon 测试面板。Sol 再审查 Secret、缓存、Memory 回归与实机 Gate；本阶段不签发 FULL FREEZE。
