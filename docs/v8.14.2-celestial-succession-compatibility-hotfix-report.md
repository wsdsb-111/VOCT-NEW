# V8.14.2 天朝制低级头衔任命兼容热修

日期：2026-10-05。兼容 Mod 版本：1.0.2。离线回归与部署完成，CK3 实机 Gate 待用户确认。

## 原因与证据

- 原版实际任命脚本位于游戏 `game/common/succession_appointment/`，并非只在 `game/dlc/` 内。`_succession_appointment.info` 明确：评分 `root` 为候选人，`scope:title` 为待任命头衔；已持有高级头衔的法理上级可以例外竞争较低级头衔。因此 `allowed_candidate_tier = lower_or_equal` 不是无例外的最高头衔门禁。
- 汉番 `common/succession_appointment/zzzz_celestial_governor.txt` 覆盖文官、武官总督任命，并保留 `lower_or_equal`。其 `common/script_values/hanfan_appointment_values.txt` 的降级/同级判断只扣 100 分，其他官阶、影响力等加分可能抵消该项。现有规则足以解释高级封臣仍可进入低级任命顺位；没有读取或改写用户存档，不将该机制解释冒充某次具体继承的运行期追踪。
- 东方王朝、天家宗仪未在本次核查的任命目录中重定义这两个 appointment key。此行为不能全部归因于两个 Mod 的冲突，原版的法理上级例外本身也有影响。

## 最小修复

源目录：`compatibility-mods/VOTC_Three_Mod_Character_Name_Compatibility/`。

- 新增 `common/script_values/votc_celestial_succession_values.txt`：候选人有领主、最高持有头衔至少为王国级、且严格高于待任命头衔时，额外扣 10000 分；其余情况返回 0。使用最高持有头衔而非姓名、官职文案或固定角色 ID。
- 新增 `common/succession_appointment/zzzzz_votc_celestial_governor.txt`：仅覆盖 `celestial_civic_governor` 和 `celestial_military_governor`，保留当前汉番全部设置与原评分项，在末尾增加该罚分，避免被前面的倍率项放大或缩小。
- 新增简中评分说明 `localization/simp_chinese/votc_celestial_succession_l_simp_chinese.yml`，UTF-8 BOM，显示“已持有更高级头衔的封臣”。
- 两描述符升至 1.0.2；汉番依赖名由旧 `oe ver.0.5` 修正为已安装版本的 `oe ver.0.55`，Mod 名称、路径和其余依赖保持不变。

范围包含王国封臣竞争公国/伯国、帝国封臣竞争王国/公国及更高等级封臣的降级竞争。同级任命、向上升迁、低于王国级人物和独立君主不扣这项分。不改普通封建世袭、其他 appointment type 或已继承的头衔。

这是用户允许的 **-10000 评分方案，不是硬性删除候选**。候选人仍可能显示在名单内；极端高额外加分或没有其他可继承候选时，不能保证永远无法当选。
