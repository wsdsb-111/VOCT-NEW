## Sol 审计修复

- 候选卡不再以 `displayName` 或 `aliasCandidate` 作为标题，统一显示“身份候选 #Runtime”；alias 只作为独立候选元数据。
- Historical Definition Bindings 页面接入最近一次只读 Prompt Diagnostics 的 identity resolution，不再保留“等待 Terra 接入”的失效文案。
- 嵌套 `participant` 中的 `score/value/contribution` 也写入 rejected numeric diagnostics，但仍不会进入 actor。
- Alias Catalog 的规范人物名改为直接读取 `figures.js`；Catalog 只维护额外别名和经 V8.4 存档勘探确认的候选 Definition ID，降低双份规范名漂移风险。
- 新增 Sol Safety Gate，直接断言 AMBIGUOUS 的候选不进入生产 `topicText`、Game Truth 为空、相关 Supplemental 命中而泛问词内容不误召回、Token 总和一致、候选标题中性、Player provenance 不可被 update payload 改写。
