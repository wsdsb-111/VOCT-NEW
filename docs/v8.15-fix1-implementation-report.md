# V8.15 修复1实施报告

日期：2026-10-06。依据用户提供的 `v8.15-修复1.md`。主代理沿用客户端模型，实现与独立 QA 子代理均为 GPT-6 Luna Max。

## 修复范围

- Explicit Target Final Selection：显式人物的 split Legacy Detail 可以替换最低分的非目标 Detail，不替换另一个显式目标；Canonical、Legacy、Derived 的预算裁剪使用同一显式目标优先级。无显式目标保留原选择行为，Detail 上限及 Packet 1200 token 上限不变。
- Durable Forget Fail-Closed：持久遗忘不确定、Owner folder 不可定位或来源不足时，在改动旧记忆与可见摘要前拒绝，返回 `MEMORY4_FORGET_INCOMPLETE`。现有 mutation journal 回滚，不报删除成功。加载时计算的 folder-summary ID 不充当真实持久来源证明。
- Safe Skip：仅当 Campaign、Owner、人物对明确，原摘要没有来源引用，该 scope 的所有合法 Memory4 sidecar 位置均不存在且 Recovery 无相关记录时，返回 `SKIPPED_SAFE_NO_FOOTPRINT`。只凭 projectionId 缺失不能安全跳过；损坏、symlink、未知文件或不确定 scope 不视为零 footprint。
- Pre-V8.15 Ghost：新增只读审计及明确确认后的遗忘。正常启动没有审计或清理钩子，不自动修改用户数据。清理复用既有 Engine/Coordinator/tombstone/journal/派生与披露撤销链路，不创建另一套物理删除算法。

没有改动 Fact Epoch、Owner/Campaign 授权、Presence、Worldline、Speaker Provenance、信件运行时代码或 Three-Mod。UI 仍显示 V8.15 / Memory Engine 4.0，协议 3.0、摘要存储 2.5、App 2.0.4、原 Prompt block IDs 和 Anchor 不变。

## 审计合同

`memory4-orphan-audit.js` 读取合法 scope 的 Canonical、Disclosure、Recovery、可见摘要与遗忘账本，返回 projection、Owner、counterpart、conversation/finalization、source IDs 及状态，不返回记忆正文。

- `ACTIVE`：可见摘要存在确切映射。
- `FORGOTTEN`：账本已经遗忘该投影，不再作为清理建议。
- `ORPHANED_PRE_V815_PROJECTION`：来源可证明、可见投影已不存在、尚未遗忘。
- `UNKNOWN`：来源、可见映射或共享正文的分离无法证明；正在生成的投影也不视为可清理 orphan。

无旧 projection lineage 时，仅单一人物对、完整 conversation/finalization 与准确 source segment 可建立候选；多人缺失 lineage 不猜测。共享 Canonical 仅在 C lineage 足以独立覆盖正文时允许遗忘 A；无法分离的共享 Legacy 来源保留并标 UNKNOWN。仍可见的 C 摘要即使没有 Canonical 候选，其真实 Legacy ID 也阻止 A 连带遗忘。缺失/非法 counterpart 的可见记录不能被忽略后误判为 orphan。

审计不写 index、metadata、known-entities、遗忘账本、entries、years、life、Legacy 或 Recovery。`auditToken` 绑定当前文件内容和审计结果；执行前重新审计，可见摘要、sidecar 或 recovery 变化均拒绝旧确认。只有 `confirmed: true` 且当前状态仍为 ORPHANED 才执行；当前 Campaign/context/write Gate 仍适用。

## 诊断接口

不新增正式管理 UI，提供现有 preload/IPC 桥接：`conversationAPI.auditMemory4Orphans` 与 `conversationAPI.forgetMemory4Orphan`。没有入口会自动确认或自动执行。开发者控制台先获取当前 context、查看 DTO，再由用户选择单一 projection 确认：

```javascript
const ctx = await conversationAPI.getMemory4OwnerData({ ownerId: 95735, contextOnly: true });
if (!ctx.success) throw new Error(ctx.error);
const request = { ownerId: ctx.ownerId, expectedCampaignToken: ctx.campaignToken, expectedContextId: ctx.contextId };
const audit = await conversationAPI.auditMemory4Orphans(request);
if (!audit.success) throw new Error(audit.error);
console.table(audit.items);
```

核对 Owner、counterpart 和来源后，使用刚刚审计返回的单一 projectionId；下例字符串必须替换为已核对的 ID，不能批量确认：

```javascript
await conversationAPI.forgetMemory4Orphan({
  ...request,
  projectionId: "替换为已核对的 ORPHANED projectionId",
  expectedAuditToken: audit.auditToken,
  confirmed: true
});
```

读取归档允许只读审计；遗忘仍要求当前有效对话上下文与当前 Owner，不对离场或结束的归档绕过写门禁。相关未知来源如需人工修复，应另行设计高风险流程，本轮不提供强制清空开关。
