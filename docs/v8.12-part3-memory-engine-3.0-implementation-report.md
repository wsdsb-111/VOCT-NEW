## 后续存档重建 P0 修复

## 后续修复：追忆中的事件经过被清理

玩家实机发现原生追忆摘要只剩人物姓名。只读检查当前 CK3 `debug.log` 后确认：`GetThirdPerspectiveDescription` 已输出完整事件，如“人物甲和人物乙成了朋友”，人物名由 CK3 链接控制码包围。通用 `removeTooltip` 按空格切词、遇到控制码就只保留控制码前的片段，使人物及其后续动作一起丢失。已仅在 `memory` 的描述字段移除已验证的 `ONCLICK`、`TOOLTIP`、`L`、`!` 标记并保留原文；未知控制码则拒绝该条描述。其他 CK3 数据字段沿用原清理规则。

回归样本覆盖含链接的人名与“被……囚禁”动作、两种 `L` 标记、多行事件及无控制码混入。当前真实日志只读抽样转换得到完整“……成了朋友”句子。已生成的旧摘要不会凭空补回被删除的内容；重启应用并开启新对话后，将从 CK3 新日志覆盖同名摘要。CK3 复制按钮使用第一人称措辞，日志提供第三人称措辞，验收应核对事件和参与人而非逐字一致。
