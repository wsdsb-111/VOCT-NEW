<a id="source-4c8c7e7daa2b--固定文案与动态原文边界"></a>
## 固定文案与动态原文边界

- Provider diagnostics 的可见固定列头和说明现在都有中英分支。原生用量、估算值、UNKNOWN／YES／NO 等状态值、请求记录、Provider／模型／路由、hash 和原始诊断 JSON 仍是技术或来源数据，测试不会把这些值当作 UI 文案替换。
- Worldline 的诊断 schema 标签（例如 Runtime、Definition、`definitionId`、`sourceComplete`、`matchedRawKeys`）显示时已本地化；字段所承载的 ID、bool、姓名、头衔、事实、日期、来源正文和补充知识内容保持原文。`UNKNOWN`、原始 JSON 与事实中出现的任意语言不会通过通用 DOM 翻译。
- Canon 编辑器固定控件已接字典，但内置示例模板 `TEMPLATES`（`world-memory-editor.js`）的样例标题和正文仍保留中文，模板按钮名称已有中英词条；这是此前明确排除的示例 Prompt 内容，不是动态游戏事实。
- Summary／Letters 的 178 个新增叶子键、Canon、Knowledge、Pair、Provider diagnostics、Optimization、Worldline 和 Prompt Builder 各自沿用受控的本地化路径；本轮没有将所有旧页面迁入 `legacyUiV951`，也没有通用 DOM 替换器。

<a id="source-4c8c7e7daa2b--边界与未覆盖项"></a>
## 边界与未覆盖项

- 顶部导航及官方追忆按钮处理由本轮其他改动负责；本文件不将其计入本矩阵。官方追忆正文仍以 CK3 原文显示；编辑说明只翻译固定 UI 外壳。
- Summary 的完整摘要正文、用户输入、来源正文和诊断 JSON 不翻译。Letters 中 Main 返回的任意错误细节及技术状态码可能继续以原文显示；本轮只翻译固定 UI 提示和明确的已知状态。
- Optimization 的既有双语覆盖来自 Renderer 内联文案，不在本轮迁入新 locale fragment。Provider diagnostics、Worldline 与 Prompt Builder 的列明固定标签已做受控双语映射；静态／专项检查不证明每种运行状态均已在打包窗口逐项目视验证。
- 追加截图范围：连接 Schema delivery、DeepSeek 选项、GLM 推理与 clear thinking、最终摘要最大输出 Token 已接双语；英文动作列表使用只读 DTO 中的原英文标题，旧执行语言保持。
- Conversation 正文、Prompt、动作结果及未列明的历史 UI 常量不在本轮覆盖。旧页面整体并未完成全面双语迁移。

<a id="source-e3ebdf0337e0--共享组件入口"></a>
## 共享组件入口

`src/app/renderer/v95/integration/react-visuals.js` 的 `createReactVisuals({ jsxRuntime, iconRegistry })` 提供 React `Icon`、`StatusBadge` 和旧 DOM 小模块可选调用的 `decorateLegacyRow`。React 页面显式传入图标名、状态码和当前显示标签；旧 DOM 调用只将图标插入传入的当前行标题节点。该模块不扫描页面、不读取业务数据、不调用 IPC。

主 Renderer bundle `src/app/renderer/assets/index-Dn3qWlAB.js` 导入工厂，并在 `jsxRuntimeExports = requireJsxRuntime()` 之后创建实例、赋给 `window.VOTCV95PageVisuals`；React root 在后续初始化。`build/runtime-inputs.json` 已登记 adapter 的 Runtime 映射。此处证明源码调用与映射声明，不证明构建或部署产物。

Renderer runtime 通过 `i18next.changeLanguage('zh'|'en')` 切换 UI 字典，并在保存独立字段后回读确认。语言切换不调用旧 `saveLanguage`、不改变 Prompt 内容或业务本地化语义。新增的 Pair 长期记忆、人物认知和 World Memory 编辑器接收受控 `t`；既有无 `t` 调用仍使用原中文。语言更新只刷新显示，不重新发送 IPC、提交写入或丢弃编辑草稿。

主 UI 对导航、流式／在场控制、上下文用量、Summary 工具栏与确认、Letters 按钮及 Provider 预算标签增加了 80 个精确 UI 替换片段。替换只覆盖固定 UI 文案；人物姓名、事实正文、Prompt 示例、动态日期和业务来源标识保持原值，不做整 DOM 自动翻译。

覆盖范围仍是分阶段迁移。Letters 开发诊断、Summary 的复杂结果信息和其他历史常量尚未完成全面双语审计；不能将当前 80 个替换片段描述成整个旧 UI 已完整翻译。新旧容器并存期间，这些未覆盖区域仍可能显示原有中文或英文。

## Intent 白名单与二次校验

所有意图都带`{type,viewKind,scopeTag,revisionTag}`；行操作加rowId。行id必须存在，disabled为false，当前View为ready且该行actions包含对应意图，Codex才继续处理。scope／revision不符直接丢弃；表现层不能更新这些标记来获取权限。
