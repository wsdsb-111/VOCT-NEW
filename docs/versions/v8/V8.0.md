# VOTC v8.0 Historical Baseline 2.0 实施报告

<a id="source-190f408aeec1--版本基线"></a>
## 版本基线

- 开发基线：v7.10.1 / `360d9ed7b212a830d429e69f98a4220792f2ff25`
- V8 Core：`8.0.0`
- Memory Engine：`2.5`
- Action System：`official-votc-2.0.3`
- UI / CK3 Workshop：`2.0.4`

用户于 2026-08-31 确认 v7.10.1 此前未完成的真实 CK3、Provider、连续重启、Action、Letter、Conversation Close、缓存和关系人工验收均已通过。该结论作为 V8.0 的已验收输入基线，不替代 V8.0 发布后的行为等价 smoke。

<a id="source-190f408aeec1--实施结果"></a>
## 实施结果

V8.0 完成 Historical Infrastructure Migration，不启用世界线 Prompt 行为：

- 18 个 legacy 年份区间、44 个事件显示项和 48 个历史人物名称已结构化；原 period、context、事件/人物文本与顺序不变。
- `schema.js` 提供 schema version 1 和全数据集交叉引用校验；无效或缺失映射直接失败，不静默忽略。
- `historical-baseline.js` 提供 `getPeriodByYear()`、`getLegacyReferenceByYear()` 和 `getBaselineSnapshot()`。
- `compatibility-adapter.js` 将内部 key 投影为 V7 四字段 legacy shape。
- `temporal-knowledge-gate.js` 提供严格中文/ISO 日期解析、日期级比较、事实/事件/人物可用性和过滤函数；未知信息 fail-safe，不影响当前 Prompt。
- 原 `game-data/legacy-historical-reference.js` 已变为兼容 wrapper，GameData 和主进程 import 无需修改。

<a id="source-190f408aeec1--未进入-v80-的后续能力"></a>
## 未进入 v8.0 的后续能力

- campaign identity 与 worldline store；
- GameStateSnapshot 与统治者解析；
- Historical Figure Resolver；
- Divergence Ledger 与 Fact Validity；
- Historical Context Projector；
- 对 `default.hbs` 或 PromptBuilder 的任何行为改动。

<a id="source-190f408aeec1--自动化验证"></a>
## 自动化验证

专项发布组：

```powershell
node scripts\test-v8.0-historical-baseline-parity.js
node scripts\test-v8.0-historical-schema.js
node scripts\test-v8.0-temporal-gate.js
node scripts\test-v8.0-prompt-compatibility.js
node scripts\test-v8.0-cache-and-boundaries.js
```

覆盖：

- 800–1400 全年 parity 和 34 个显式边界；
- notableEvents / notableFigures 顺序；
- duplicate/overlap/range/reference/date/sensitivity schema 失败；
- 过去、未来、同日和未知日期 fail-safe；
- 900、1010、1105、1130、1265、1280 的 world_context 字节级等价；
- `default.hbs` 与稳定段 SHA-256、stable/dynamic 分类及 deferred world context；
- historical-system 不依赖冻结模块，且未提前创建 v8.1+ 模块。

完整 release gate 已由 `node scripts\test-release.js` 执行并输出 `VOTC v8.0 Historical Baseline 2.0 Release Regression: PASS (67 groups)`；测试清单覆盖 136 个 `test-*.js`。自动化通过证明结构迁移和现有代码非回归，不等同于 V8.0 的 CK3 行为等价 smoke。
