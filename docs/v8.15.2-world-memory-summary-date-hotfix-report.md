# V8.15.2 世界记忆保存与摘要日期排序热修

日期：2026-10-07。主代理沿用客户端模型；实现支线及独立 QA 使用 GPT-6 Luna Max。

## 世界记忆保存

真实隔离 VOTC.exe 复现：普通剧情事实使用 CURRENT_DATE 保存时，Canon worker 已写入 `1082.1.1`，但保存返回前的 `checkpoint_active` 通知使 Renderer 请求世代失效。界面丢弃保存结果和错误，表现为点击后无反馈。这是后台更新与保存的竞态，不是当前日期格式本身非法；指定日期也保留同样的竞态保护。

`resources/app/out/renderer/world-memory-editor.js` 在操作期间暂存需要重读的世界线通知，保持按钮禁用，操作结束后读取当前分支。成功结果正常显示，失败提示不被吞掉；不自动重试保存。空闲时的真正存档变化仍使旧界面失效。

CURRENT_DATE 仍由服务端日期与天数决定，不信任 Renderer 提交值。Canon token、Campaign/branch、Current Truth 核验及 Worker 权限未改。跨战役切换时旧 token 被拒绝，旧草稿不写入新分支。

## 摘要排序

`resources/app/out/renderer/summary-date-order.js` 为摘要生成显示投影 `{ summary, index }`；bundled 摘要管理器默认按日期降序排列每个对话文件的条目。新增“按日期排序”按钮，可切换回原文件顺序；恢复失败摘要并刷新后继续按所选模式显示。

点、斜线、横线及中文年月日按数值比较；同日保留原顺序，无日期或非法日期放最后。最近日期在上，例如九月在八月上方。只调整显示，不重写 JSON、不调整人物文件分组或记忆召回顺序。编辑、删除和模型整理继续使用原文件索引，防止操作错条目。
