# V8.15 Memory4 召回与删除一致性实施报告

日期：2026-10-06。依据用户提供的《v8.15-Memory4召回与删除一致性修复方案 (1)》。主代理使用客户端选定模型；实现与独立 QA 子代理均为 GPT-6 Luna Max。

## 范围与合同

- Presence 只描述本场可见经历，不决定历史人物能否成为召回目标。`explicitTargetEntityIds`、`activeParticipantIds`、`mentionedOutOfSceneIds` 独立传递；显式查询在场 C 与场外 D 都搜索回应者自己的完整摘要目录，不读取目标的私人目录。
- Entity、Topic、Lexical 任一可信命中可建立候选；唯一全名优先于相邻的歧义头衔。泛问不自动召回所有在场人物，短名不匹配另一个长名，仅共享单汉字不构成词面资格。
- 未能证明完整迁移的 Legacy Narrative 保留。仅可靠格式且逐事实完整覆盖时排除已转换部分；部分迁移、未知标题、缺失引用和过时哈希不整篇删除父摘要。长摘要可提取问题附近的中段，原始来源哈希继续用于历史复用验证；旧承诺不证明当前仍有效。
- 删除写入 Campaign/Owner 内的 `forgotten-projections.json`，先持久化稳定 projection tombstone，再处理正文、索引、披露、派生记忆与恢复任务。参与现有摘要 mutation journal；失败回滚，不留下半次删除。多人同 finalization 的 B-A 与 B-C 独立处理，共享来源必须保留仍有效的 C 证据。
- 删除清理真正的 frozen Prefix、动态历史和人物摘要缓存，但不删除当前消息、滚动摘要或本场角色快照。已有冻结披露只撤销失效事实，不在本场追加新披露。
- 旧信件以已验证 Episode 的 letter ID、人物对、正文、日期及 Memory 来源精确补映射；收件人删除只撤销自己的信件认知，发件人保留。信件可见摘要保存、迟到的 Legacy 保存及 Owner 重试都检查持久遗忘，不能重新写回摘要或授权被删除的接收者。
- 旧披露仅在 message/segment/letter 来源可精确定位时撤销；同 finalization 的独立 C 证据不被误删。相关但缺失或部分映射的旧 proof 会拒绝 mutation 并回滚，不能冒充删除成功。共享来源保留真实 Presence、knownBy 和 source revision，只撤销被删除的人物对投影。
- 人物记忆显示标签仍为 Memory Engine 4.0；协议 `engineVersion: 3.0`、摘要 2.5、现有目录与 Prompt block IDs 保持兼容。人物召回沿现有动态 `memory-temporal-extra` 块，未新增缓存 Anchor。版本显示为 V8.15，Electron 包版本仍为 2.0.4。

## 实现位置

- `resources/app/out/main/conversation/conversation.js` 与 `memory-system/memory-engine.js`：显式人物路由、去重、来源传递及实际冻结缓存失效。
- `memory-system/mention-tracker.js`、`memory4-recall-planner.js`：姓名消歧、正文级候选资格、Legacy 完整覆盖与预算。
- `memory-system/memory4-forget.js`、`memory4-store.js`、`memory4-coordinator.js`、`memory-store.js`：稳定投影身份、持久遗忘、逐摘要过滤、恢复及提交门禁。
- `memory-system/memory4-derived.js`：清理引用被遗忘来源的 Year/Life 正文，来源 DTO 不返回被删除事实；保留无关手工内容。
- `game-data/game-data.js` 与 `memory-system/letter-memory-finalization.js`：可见摘要和信件来源映射，不伪造信件的物理 Presence 或 message ID。
- `summaries/summaries-manager.js`、`memory-system/memory-trace.js`、`analytics/usage-analytics.js`：生产编辑/删除接线与有限 ID/计数诊断，不记录新增完整问题或正文。

1. L1 游戏加载/bootstrap。
2. L2 过期信件投递和摘要。
3. L3 无重复信件、摘要或效果。
4. L4 对话场景保存/读取。
5. L5 A+B 对话中询问第三人 C。
6. L6 A+B+C 对话中明确询问在场 C，召回资格与 L5 等价。
7. L7 删除摘要，完全退出并重启 App 后确认对应事实不再进入召回；仍保留其他人物对证据。
