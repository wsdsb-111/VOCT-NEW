# V8.7.0a 前置修复

依据新版 v8.7.md，完成五项 Pre-V8.7 Cleanup。按用户要求在主体开发前暂停。

- 家庭事实缺少致死者时，允许使用后续获准的 Current Game Truth / Worldline Game Truth；禁止从 Memory 或模型推测。
- 最近第三人明确提名后的 3 个用户轮次内允许指代，指代本身不续期；超过有效期记录 UNRESOLVED_COREFERENCE。
- 历史重置同时清除当前轮、最近第三人和轮次/消息位置。
- 同最高权威矛盾保持 EVIDENCE_CONFLICT；不同权威记录使用 HIGH_AUTHORITY_SELECTED / LOW_AUTHORITY_CONTESTED，保留相反说法。
- 亲属图缓存去掉每日 totalDays 与通用 gameDataRevision，使用结构 revision、关系指纹、战役与检查点；嵌套亲属死亡字段和配偶列表变化触发失效。
