# V8.6.1 Luna Stage 5 实施报告：Diagnostics / Token / Cache UI

日期：2026-09-07

## 结论

Luna Stage 5 已完成。世界线诊断页现在可以通过既有 preload `usageAPI` 读取本机已持久化的对话观测元数据，展示 Memory / Worldline 分块 Token、Provider 与内部缓存层、关键耗时以及最近一条对话的来源；生产 Prompt 路由和默认开关没有改变。

## 已完成

- 在世界线“诊断”页新增只读 `Token / Cache 观测` 面板，可手动刷新，不读取或渲染 Prompt 正文。
- 展示 Provider 输入、命中/未命中 Token、缓存率、输出 Token、稳定前缀/动态后缀。
- 展示 Memory stable/direct/topic/turn recall 与 Worldline stable/turn recall Token。
- 分开显示 Worldline shared cache、Worldline subjective cache、Memory recall、Worldline retrieval/policy/Prompt build 耗时；不把内部缓存命中冒充 Provider KV Cache 命中。
- 复用已有 `usageAPI → usage:getReport` preload 边界，没有新增客户端可提交的授权字段，也没有把观测数据写回存档或补充知识。
- 补充知识编辑器明确标注当前会话 / 当前检查点范围，并说明 Personal / Secret 需要可验证 CK3 Runtime ID 才能作为角色范围，不会自动共享给其他角色。
- 保留既有 Prompt / World Recall、角色认知、A/B 和 Secret 计数诊断入口；`subjectiveWorldMode=DIAGNOSTIC`、`promptIntegrationEnabled=false` 保持不变。
