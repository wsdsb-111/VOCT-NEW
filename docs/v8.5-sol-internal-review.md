## 发现与修复

### P0：诊断裁剪列表没有 IPC / DOM 上限

真实持久化 Checkpoint 文件约 97 MB，包含 42,312 条年度变化。“岳飞”诊断产生 42,313 条裁剪项，JSON 约 462 万字符。后端约 141 ms 返回；前端在折叠的 `<details>` 中仍立即创建所有子节点。离线同构回归记录到 **169,404 次 JSX 节点创建**，足以解释收到候选后页面失去响应的现象。

修复：

- `getPromptDiagnostics` 新增 `trimmedPage` 输入以及 `trimmedTotal/trimmedPage/trimmedPageSize` 输出；每页 50 条，页号夹紧，最后一页可达。
- `trimmedItems` 现在明确是当前页，而非完整数组；旧 IPC 名称保留。生产 Renderer 同步升级，其他消费者需要依据总数和页号读取全部记录。
- 不删除持久化 Delta；服务保留完整裁剪记录，按需复制页数据，不再复制整个数组到 IPC。
- Resolver 高级内容只在展开后构建；列表另有 50 条防御上限，旧后端超大响应也不会再次生成十几万个节点。
- 页面提供上一页/下一页。分页沿用诊断的查询，不误用输入框中尚未提交的新文本。

### P1：本地化冷查询仍可同步阻塞 Main

精确人物命中跳过反查不能保护未知名字或本地化头衔。现在文件发现与扫描由 `localization-worker-client.js` 后台 Worker 执行；同步 Prompt 只读取已完成的缓存，不等待磁盘扫描。

- IPC 诊断走异步门面，最多等待约 8 秒；仍未完成时返回 `localizationPending`，玩家界面提示稍后重试，不把未完成搜索说成角色不存在。
- 单次后台任务 30 秒超时、队列最多 32 个、缓存最多 512 项；相同请求合并，线程失败后不循环重启。
- 来源文件签名变化或显式 invalidate 会终止旧线程，丢弃迟到结果；checkpoint 在异步等待中变化时返回 `CHECKPOINT_CHANGED`。
- 本地化 revision 进入 topic cache identity；线程完成后刷新展示并失效相关缓存。未完成/冲突的证据不自动成为身份确认。

### P1：时间、相关性与可见性

- Runtime/Definition ID 中的数字不再被截作年份，例如 `#96896`、`121091`、`han_12371`。
- 无效日历日期和反向年份范围拒绝召回；现在/近期查询也过滤未来日期，`dateRange` 不能绕过门禁。即便请求未来年份，事实 horizon 仍不得超过 Checkpoint。
- 已有实体的“最近发生了什么”不再启用全世界 Delta；战争问题限制对应事件类型。
- Supplemental 缺失 visibility 或 truthy hidden 不按公开事实处理。仍仅 PUBLIC_WORLD 可进入 Prompt，不引入 V8.6 权限扩散。

### P1：缓存与 Token

- 相关 Supplemental 的 importance/source 纳入结构化 revision，防止优先级变化后继续命中旧排序。
- Summary key 包含查询、实体、Live/Checkpoint 和本地化 revision；切换检查点清空 summary cache。
- topic cache 上限 8，summary cache 上限 64；不再把完整 ranked candidate 对象图重复保存在每条 topic context 中。
- 删除可裁剪候选后，固定区块仍超 1200 token 则返回无世界注入，不能仅标记超预算却继续输出。

### 展示正确性

- 未知领主证据不再展示为“无直接领主”；只有 INDEPENDENT 才能表达独立。
- Player World Knowledge DTO 保留主头衔本地化冲突来源和 warning，不丢失多个名称候选。
- 诊断长状态文本允许在网格内换行，避免覆盖相邻值。
- 历史映射在无筛选且已有 500 条结果后只计数；不再为其余九万条建立展示对象。搜索仍覆盖完整索引。

- 未写游戏存档、用户配置、Supplemental 或记忆；Prompt Default On 仍未打开。没有调用付费模型来制造测试量。
