# V8.7.2 Terra 实施报告：Current Truth、载入边界与 Legacy 迁移

## 已实现

- 新增 `current-truth-adapter.js`，将可写 Current Claim 收敛为位置、生死、信仰、文化、直属领主与所在宫廷六项。普通可读事实文本继续进入知识/Prompt；机器核对只使用 `structuredValue`，并保存 `displayValue` 供玩家界面显示。
- `primaryTitle` 与 `imprisoned` 没有当前存档解析的等价生产来源，Current Claim 写入因此 fail-closed；不会再以测试夹具可构造为由向玩家宣称支持。
- Canon 写入会从当前 Checkpoint 重新取得原始值，拒绝手工伪造值；同一适配器服务 Canon 召回、World Fact 和测试 API。
- Branch Registry 新增 `loadSessionId`：已存在标识时，同路径、日期前进的 autosave 只在相同载入会话内自动延续；标识变更或缺失会返回 `LOAD_BOUNDARY_CANDIDATE`，必须继续当前分支、恢复已知 fingerprint 或新建分支。预 V8.7.2 的无标识历史条目仍兼容原有 autosave 延续。
- Workshop Mod 增加 `common/on_action/votc_load_boundary.txt`，在 CK3 启动/载入时递增持久化 epoch 并输出 `VOTC:LOAD_SESSION`。桌面端只读取该 opaque marker，不改写 CK3 存档事实。
- Legacy Supplemental 维持可读；面向玩家的旧 IPC 写接口改为 `legacy_supplemental_read_only`。公开记录可迁移为 Canon；Personal/Secret/Court 记录先返回审阅草稿。Canon 成功后旧记录才标记迁移并退出旧召回；`legacyMigrationId` 使重试幂等，防止双重注入。
