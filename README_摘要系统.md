## 🎯 核心功能

### ✅ 记忆共享
无论谁发起对话，都能访问相同的历史记忆

### ✅ 人类可读
文件夹和文件都使用角色名字，不再是ID

### ✅ 跨角色记忆
B能想起与C的对话（当A提到C时）

### ✅ 动态加载
只在提到其他角色时才加载相关记忆，节省46% token

## 💡 工作原理

### 普通对话（90%情况）
```
赵匡胤: "最近如何？"
李煜: "还好"

加载：赵匡胤 ↔ 李煜（3条摘要）
Token：~300 ✅ 节省50%
```

### 提到其他角色（10%情况）
```
赵匡胤: "你和周娥皇聊了什么？"
李煜: [准备回复]

检测：🎯 发现"周娥皇"
动态加载：李煜 ↔ 周娥皇（2条摘要）
加载：赵匡胤 ↔ 李煜（3条摘要）
Token：~500

李煜: "我和她讨论了..." ✅ 能想起来！
```

## 🐛 常见问题

### Q: 提到了角色但没想起来？
A: 检查控制台是否有"动态加载"日志，确认角色名字完全匹配

### Q: Token使用仍然很高？
A: 正常，如果对话频繁提到多个角色。可以减少每个角色的摘要数量

### Q: 找不到旧的对话记录？
A: 旧文件已备份为 `.backup`，可以恢复
